# Backend

独立后端 API 服务，负责认证、文章、评论、管理和数据库访问。

## 开发

```bash
npm install
npm run dev
```

## 生产

```bash
npm run start
```

建议使用 `ecosystem.config.cjs` 配合 PM2。

## 媒体上传

媒体管理通过 `/api/admin/media-uploads` 创建单文件任务，以 2MB 分片顺序传输，
按服务器确认的字节偏移续传；完成接口通过固定资源 ID 幂等入库。
任务和临时文件保存在上传目录同级 `.media-tmp/resumable` 中，不公开提供静态访问。
暂停或失败后，在任务清单内继续上传可复用已有进度；关闭弹窗或切换页面后，
全局队列继续上传，可从控制台右上角查看进度。取消上传才会清理未完成的临时任务，
不会删除已入库资源。刷新或关闭浏览器标签页会停止上传。服务启动及每小时清理
超过 24 小时未活动的任务和旧临时文件。

现有 `/api/admin/media` 整文件接口保留。`HTTP_REQUEST_TIMEOUT_MS` 默认 30 分钟，
用于避免 Node 默认 5 分钟接收期限中断慢网络上传；Nginx/CDN 仍需允许分片请求。
上传的并发、总量和磁盘安全余量继续由 `MEDIA_UPLOAD_*` 配置控制。
任务锁与并发保护基于当前 PM2 单进程 fork 部署，多实例部署前需要改为共享锁和配额。
