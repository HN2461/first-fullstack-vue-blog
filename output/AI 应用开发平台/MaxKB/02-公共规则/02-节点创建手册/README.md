# MaxKB 逐节点创建配置手册

> 文档状态（2026-07-01）：本目录是给 AI 和人一起使用的 MaxKB 节点配置防忘清单。核心目标是：后续教用户创建节点时，不少说参数、不多编参数。

## 1. 使用方式

优先读：

```text
00-AI创建节点必读.md
```

再按需打开具体节点文件。

不要一次性加载全部文件。

如果后续把本目录给 AI 使用，阅读规则是：

```text
1. 先读 00-AI创建节点必读.md。
2. 用户问哪个节点，就只读哪个节点文件。
3. 回答时只说该节点真实存在的配置项。
4. 不要把其他节点的参数套过来。
```

如果只想复制最小防忘清单，复制：

```text
README.md
00-AI创建节点必读.md
```

如果还要某个节点的具体配置，再复制对应节点文件。

```text
1. 本目录只保留 MaxKB 实际配置项和必要提醒。
2. 不写大段教程，不重复解释通用规则。
3. 通用防忘规则统一写在 00-AI创建节点必读.md。
4. 单个节点文件只记录该节点真实配置、输出参数、易错点。
```
