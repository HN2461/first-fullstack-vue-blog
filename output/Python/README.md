# Python 学习资料总目录

这个目录用于收纳 Python 学习资料，先把基础概念和应用实例分开，后续再逐步补工程化、项目实战和面试复盘。

## 01-知识目录

放基础概念类内容。

当前已经整理：

- Python 零基础入门 00-23
- 变量、字符串、数字、输入、条件判断、循环
- 列表、元组、集合、字典
- 函数、文件读写、异常处理
- 模块、包、pip、虚拟环境
- 面向对象、常用标准库、csv 模块、logging 日志模块、面试复盘

这部分是“先把语言本身学会”，不要急着上框架。后续如果继续补基础知识，可以放：

- Python 进阶语法
- 正则表达式
- 日期时间处理
- JSON / CSV / Excel 文件处理
- 命令行脚本
- 单元测试基础

## 02-应用实例

放能动手做出来的应用方向。

当前先分两类：

- 网络爬虫与数据分析：请求网页、解析 HTML、保存 CSV、用 pandas 做统计。
- Web 入门：用 Flask / FastAPI 做接口，理解后端项目怎么接收请求、返回数据，并逐步过渡到公司项目开发。

这部分不是为了追求大项目，而是为了把基础知识接到真实场景里。比如：

- 字符串：清洗标题、标签、链接。
- 列表和字典：保存一组数据记录。
- 文件读写：把结果保存成 CSV / JSON。
- 异常处理：处理网络失败、解析失败、文件不存在。
- 模块和虚拟环境：安装 requests、beautifulsoup4、pandas、flask、fastapi。

## 03-工具链与工程化

放项目开发习惯和环境管理内容。

后续可以补：

- 虚拟环境与依赖文件
- pip / uv / poetry 的区别
- 项目目录结构
- 配置文件与环境变量
- 多模块日志配置与集中采集
- 单元测试 pytest
- 代码格式化和 lint

## 建议学习顺序

1. 先读完 `01-知识目录` 的零基础入门文章。
2. 再做 `02-应用实例/网络爬虫与数据分析`，因为它主要用基础语法、文件、异常和第三方库。
3. 再做 `02-应用实例/Web入门`，理解 Python 怎么写后端接口。
4. 最后补 `03-工具链与工程化`，把脚本式学习逐步过渡到项目式开发。

## 命名约定

文章文件继续使用编号开头，便于知识库导入后排序。

应用文章不强行和零基础编号混在一起，因为它们属于不同学习阶段。比如：

- `00-Python网络爬虫入门-基础概念.md`
- `01-Python网络爬虫入门-请求网页与robots.txt.md`
- `02-Python网络爬虫入门-lxml解析HTML并保存CSV.md`
- `01-Python-Web入门-Flask最小接口.md`
- `04-Python-Web入门-FastAPI公司项目开发手册.md`

FastAPI 学习建议按以下顺序阅读：

1. `02-应用实例/Web入门/01-Python-Web入门-Flask最小接口.md`：先理解路由、请求和响应。
2. `02-应用实例/Web入门/02-Python-Web入门-FastAPI最小接口.md`：掌握类型校验和自动文档。
3. `02-应用实例/Web入门/04-Python-Web入门-FastAPI公司项目开发手册.md`：按项目骨架练习配置、数据库、认证、测试和部署。
4. `02-应用实例/Web入门/03-Python-Web入门-Flask-FastAPI-Django怎么选.md`：根据业务场景补充框架选型判断。

这样后续补文章时可以直接追加，不会破坏已经学过的基础主线。
