# 08-知识库相关节点速查

> 文档状态（2026-07-19）：根据空白高级智能体验证截图和 MaxKB v2.10.4 官方文档，记录知识库相关节点基础配置。
> 当前口径：项目工作流主链路暂未依赖知识库节点，但后续做知识问答、政策制度检索、跨项目知识库场景时可能使用，先沉淀基础配置和组合方式。
>
> 官方依据：[高级智能体 - 知识库节点](https://maxkb.cn/docs/v2/user_manual/app/workflow_app/#22)、[知识库命中测试](https://maxkb.cn/docs/v2/user_manual/dataset/hit-testing/)

## 1. 当前结论

本文件覆盖这些知识库相关节点：

```text
文档内容提取
文档标签检索
知识库检索
多路召回
```

推荐理解：

```text
1. 文档内容提取：从选择的文档中直接提取内容。
2. 文档标签检索：按文档标签筛选出知识库和文档列表。
3. 知识库检索：在关联知识库中检索和问题相关的分段。
4. 多路召回：把多个检索结果用重排模型再排序和压缩。
```

常见组合：

```text
开始 / 问题优化
  -> 文档标签检索（可选，先缩小知识库或文档范围）
  -> 知识库检索（检索相关分段）
  -> 多路召回（可选，对多个检索结果重排）
  -> AI 对话（基于检索结果回答）
  -> 指定回复
```

## 2. 文档内容提取

节点入口：

```text
基础组件 -> 知识库 -> 文档内容提取
```

官方说明：

```text
提取文档中的内容。
```

当前截图可见配置：

| 配置项 | 初始状态 / 可见内容 | 说明 |
| --- | --- | --- |
| 选择文档 | 下拉占位为 `请选择文档` | 必填，选择要提取内容的文档来源 |
| 输出参数 | `文档内容(content)`、`文档列表(document_list)` | 后续节点可引用 |

输出参数：

| 显示名称 | 变量名 | 说明 |
| --- | --- | --- |
| 文档内容 | `content` | 提取后的文档正文内容 |
| 文档列表 | `document_list` | 文档列表数组 |

使用建议：

```text
1. 适合用户明确选择文档后直接提取全文或摘要前置内容。
2. 不适合大范围知识问答检索，大范围问答优先用知识库检索。
3. 如果文档很长，后面接 AI 对话时要注意 token 和最大引用字符数。
```

## 3. 文档标签检索

节点入口：

```text
基础组件 -> 知识库 -> 文档标签检索
```

官方说明：

```text
根据设置的文档标签筛选条件检索出符合条件的文档。
该节点通常配合知识库检索节点使用，先缩小文档范围，再进行分段内容检索。
```

当前截图可见配置：

| 配置项 | 初始状态 / 可见内容 | 说明 |
| --- | --- | --- |
| 检索范围 | 右侧有 `+` 和范围来源下拉，当前为 `自定义` | 选择关联知识库或引用变量 |
| 添加关联知识库弹窗 | 标题为 `添加关联知识库`，提示所选知识库必须使用相同 Embedding 模型 | 多知识库检索时必须注意 Embedding 模型一致 |
| 检索设置 | `自动 / 手动` 单选 | 自动按检索问题匹配标签；手动添加标签过滤条件 |
| 检索问题 | 下拉占位为 `请选择检索问题` | 必填，作为自动标签匹配的问题来源 |
| 输出参数 | `知识库列表(knowledge_list)`、`文档列表(document_list)` | 后续知识库检索可引用 |

官方节点设置补充：

```text
1. 检索范围：
   - 手动：添加关联知识库。
   - 引用变量：选择工作流中已存在的知识库列表或文档列表变量。
2. 检索设置：
   - 自动：选定检索问题，系统按问题自动匹配文档标签。
   - 手动：添加标签条件作为过滤条件。
```

输出参数：

| 显示名称 | 变量名 | 说明 |
| --- | --- | --- |
| 知识库列表 | `knowledge_list` | 符合标签条件的知识库列表 |
| 文档列表 | `document_list` | 符合标签条件的文档列表 |

使用建议：

```text
1. 当知识库文档很多、标签体系完整时，先用文档标签检索缩小范围。
2. 如果知识库没有维护标签，该节点价值有限。
3. 自动标签适合泛化问题，手动标签适合固定业务域，例如“工作流制度”“请假规则”“报销制度”。
4. 添加多个关联知识库时，必须确认 Embedding 模型一致。
```

## 4. 知识库检索

节点入口：

```text
基础组件 -> 知识库 -> 知识库检索
```

官方说明：

```text
关联知识库，检索与问题相关分段的节点。
```

当前截图可见配置：

| 配置项 | 初始状态 / 可见内容 | 说明 |
| --- | --- | --- |
| 检索范围 | 右侧有 `+` 和范围来源下拉，当前为 `自定义` | 添加关联知识库或引用前置知识库/文档变量 |
| 检索参数 | 可点齿轮打开参数设置 | 控制检索模式、相似度、引用段数、最大字符数 |
| 检索模式 | 当前显示 `向量检索` | 可在参数设置里切换 |
| 相似度高于 | 当前显示 `0.600` | 分段相似度阈值 |
| 引用分段数 TOP | 当前显示 `3` | 取前几个分段 |
| 最多引用字符数 | 当前显示 `5000` | 控制拼接内容长度 |
| 检索问题 | 下拉占位为 `请选择检索问题` | 必填，选择用户问题或优化后的问题 |
| 结果显示在知识来源中 | 开关关闭 | 是否在前台知识来源里展示结果，具体效果待回归 |
| 输出参数 | `paragraph_list`、`is_hit_handling_method_list`、`data`、`directly_return` | 后续节点可引用 |

参数设置弹窗可见：

| 参数 | 当前截图值 | 说明 |
| --- | --- | --- |
| 检索模式 | 向量检索 / 全文检索 / 混合检索 | 不同检索策略 |
| 相似度高于 | `0.600` | 低于阈值的分段过滤 |
| 引用分段数 TOP | `3` | 返回前 N 个分段 |
| 最多引用字符数 | `5000` | 限制引用内容长度 |

检索模式说明：

| 模式 | 截图说明 | 适合场景 |
| --- | --- | --- |
| 向量检索 | 基于向量相似度，适用于知识库中的大数据量场景 | 语义相似、问法多样 |
| 全文检索 | 基于文本相似度，适用于知识库中的小数据量场景 | 关键词精确匹配 |
| 混合检索 | 基于向量和文本相似度，适用于知识库中的中等数据量场景 | 同时兼顾语义和关键词 |

输出参数：

| 显示名称 | 变量名 | 说明 |
| --- | --- | --- |
| 检索结果的分段列表 | `paragraph_list` | 检索命中的分段列表 |
| 满足直接回答的分段列表 | `is_hit_handling_method_list` | 满足直接回答条件的分段列表 |
| 检索结果 | `data` | 检索结果内容 |
| 满足直接回答的分段内容 | `directly_return` | 可直接返回的分段内容 |

使用建议：

```text
1. 检索问题优先绑定 `问题优化.answer` 或 `开始.question`。
2. 如果用户输入不规范，可以先走问题优化，再走知识库检索。
3. 如果知识库很多，先用文档标签检索缩小范围，再做知识库检索。
4. 如果结果要给 AI 对话使用，注意最大引用字符数，避免上下文过长。
5. 工作流申请主链路里的真实提交、草稿保存、审批人选择，不应依赖知识库检索结果。
```

## 5. 多路召回

节点入口：

```text
基础组件 -> 知识库 -> 多路召回
```

官方说明：

```text
根据需要重排的内容、检索问题以及检索参数进行多路召回。
```

当前截图可见配置：

| 配置项 | 初始状态 / 可见内容 | 说明 |
| --- | --- | --- |
| 重排内容 | 下拉占位为 `请选择重排内容`，右侧有 `+` 可添加 | 必填，可添加多个检索结果 |
| 检索参数 | 可点齿轮打开参数设置 | 控制 score、TOP、最大字符数 |
| Score 高于 | 当前显示 `0.000` | 重排后分数阈值 |
| 引用分段 TOP | 当前显示 `3` | 取前几个重排分段 |
| 最大引用字符数 | 当前显示 `5000` | 控制最终拼接长度 |
| 检索问题 | 下拉占位为 `检索问题` | 必填，通常绑定用户问题或问题优化结果 |
| 重排模型 | 右侧模型来源为 `自定义`，下方需选择重排模型 | 必填 |
| 结果显示在知识来源中 | 开关关闭 | 是否显示知识来源，具体效果待回归 |
| 输出参数 | `result_list`、`result`、`is_hit_handling_method_list` | 后续节点可引用 |

官方节点设置补充：

```text
1. 重排内容：待重排的多个内容，一般是多个不同知识库的检索结果。
2. 检索参数：包括 score 阈值、引用分段数以及最大引用字符数。
3. 检索问题：根据检索问题进行重排，一般为用户问题或问题优化后的结果。
4. 重排模型：需要使用的重排模型名称。
```

输出参数：

| 显示名称 | 变量名 | 说明 |
| --- | --- | --- |
| 重排结果列表 | `result_list` | 重排后的结果列表 |
| 重排结果 | `result` | 根据检索参数处理后的重排结果文本 |
| 满足直接回答的分段列表 | `is_hit_handling_method_list` | 根据检索参数后的命中列表 |

使用建议：

```text
1. 适合多知识库、多来源检索结果需要二次排序的场景。
2. 只有一个检索来源时，先不急着用多路召回。
3. 必须先配置重排模型，否则节点无法发挥作用。
4. 多路召回后再接 AI 对话，可以让 AI 基于更干净的上下文回答。
```

## 6. 推荐组合模板

### 6.1 简单知识库问答

```text
开始
  -> 问题优化
  -> 知识库检索
  -> AI 对话
  -> 指定回复
```

绑定建议：

```text
知识库检索.检索问题 = 问题优化.answer
AI 对话.用户提示词 = 知识库检索.data + 开始.question
```

### 6.2 标签过滤后检索

```text
开始
  -> 问题优化
  -> 文档标签检索
  -> 知识库检索
  -> AI 对话
```

适合：

```text
知识库有标签体系，需要按业务域、制度类别、角色权限先筛选文档。
```

### 6.3 多知识库重排

```text
开始
  -> 问题优化
  -> 知识库检索 A
  -> 知识库检索 B
  -> 多路召回
  -> AI 对话
```

适合：

```text
多个知识库都可能有答案，需要统一重排再回答。
```

## 7. 与当前工作流项目的关系

普通工作流主链路重点是：

```text
流程选择
动态表单字段解析
草稿保存
正式提交
审批人选择
附件组件处理
```

这些核心动作不建议交给知识库节点。

知识库节点更适合未来扩展：

```text
1. 用户问“请假制度是什么”。
2. 用户问“报销需要哪些材料”。
3. 用户问“某类流程办理说明”。
4. 项目迁移到其他知识问答型场景。
5. 工作流发起前，先检索制度说明或材料清单。
```

## 8. 易错点

```text
1. 没有选择检索问题，知识库检索会报必填或无法执行。
2. 添加多个知识库时 Embedding 模型不一致。
3. 把知识库检索结果当成真实业务权限或审批结果。
4. 最大引用字符数太大，导致 AI 对话上下文过长。
5. 相似度阈值太低，召回无关内容；太高，可能没有结果。
6. 结果显示在知识来源中打开后，前台展示效果未验证。
7. 多路召回没有配置重排模型。
8. 文档标签检索依赖标签体系，知识库未打标签时不要强行使用。
```

## 9. 资料依据

MaxKB 官方高级智能体文档说明：

```text
文档标签检索：根据设置的文档标签筛选条件检索出符合条件的文档。
多路召回：根据需要重排的内容、检索问题以及检索参数进行多路召回。
知识库检索：关联知识库，检索与问题相关分段的节点。
文档内容提取：提取文档中的内容。
```

MaxKB 产品说明也把 RAG 检索增强作为核心能力：支持上传文档、自动拆分、向量化和检索增强生成，用于减少大模型幻觉。
