# 00：空白高级智能体创建说明
> 文档状态（2026-07-03）：本文记录创建 MaxKB 空白高级智能体的方法，以及维护节点创建手册的通用规则。它不是项目进度记录，也不要求其他项目沿用固定智能体名称。

## 1. 用途

创建空白高级智能体，主要用于：

```text
1. 核对 MaxKB 节点在当前版本里的真实配置项。
2. 测试节点默认输出、连线方式和运行效果。
3. 为节点创建手册补充截图结论和易错点。
4. 验证新节点或新组合，再决定是否迁入正式业务智能体。
```

空白智能体只作为学习和验证环境，不承接正式业务链路。

## 2. 创建步骤

在 MaxKB 中按下面步骤创建：

```text
1. 进入顶部“智能体”。
2. 点击右上角“创建”。
3. 选择“高级智能体”。
4. 名称填写一个明确的测试名称，例如“节点配置验证”。
5. 描述填写用途，例如“用于验证 MaxKB 节点配置项和输出参数”。
6. 模板选择“空白创建”。
7. 点击“创建”。
8. 进入画布后，默认只有“基本信息”和“开始”两个区域。
```

名称和描述可以按团队习惯调整，不影响后续节点手册使用。

## 3. 使用边界

空白高级智能体不要用于：

```text
正式发布入口
真实用户对话
业务提交、审批、保存草稿
生产环境密钥、真实用户 token 或真实业务数据测试
```

如果要验证真实接口，优先使用脱敏参数、测试账号和测试环境，并在验证后清理临时节点。

## 4. 节点手册维护规则

本目录按节点拆分，避免一个大文件混入太多无关内容：

```text
02-节点创建手册/
  README.md
  00-AI创建节点必读.md
  00-空白高级智能体创建说明.md
  01-添加组件面板总览.md
  02-基本信息与开始节点.md
  ...
```

维护单个节点文件时，优先使用下面结构：

```text
1. 节点定位
2. 创建入口
3. 初始配置项
4. 输入 / 输出参数
5. 通用用法
6. 易错点
7. 待继续核对
```

## 5. 记录原则

写节点手册时只记录已经确认的内容：

```text
1. 只写 MaxKB 界面真实存在的配置项。
2. 没点开、没验证、版本不确定的内容放到“待继续核对”。
3. 示例字段使用可替换名称，不写真实环境地址、真实账号或密钥。
4. 项目案例只保留为通用方法，不写完整业务流水账。
5. 如果某个结论只对单个项目有效，应迁入对应项目进度目录。
```

## 6. 复用建议

把本规范包迁移到其他项目时，建议保留本文。

原因是：不同 MaxKB 版本的节点界面可能略有差异，后续 AI 或开发者可以先创建一个空白高级智能体做最小验证，再按验证结果更新节点手册。
