# 09：表单收集节点
> 文档状态（2026-07-19）：根据空白高级智能体验证截图、附件通用验证记录和 MaxKB v2.10.4 官方资料，记录表单收集节点配置、组件类型、显隐条件和工作流项目使用建议。

## 1. 节点定位

`表单收集` 属于添加组件面板中的：

```text
基础组件 -> 业务逻辑 -> 表单收集
```

官方说明：

```text
通过表单的设计，以引导的方式主动获取必要的信息，一般应用于需要多次询问的应答场景。
```

通用理解：

```text
表单收集不是普通 AI 理解节点，而是结构化收集用户输入的表单节点。
它适合收集明确字段、附件、选择项、日期、开关等信息。
```

## 2. 当前节点初始配置

当前截图中表单收集节点显示：

| 配置项 | 初始状态 / 可见内容 | 说明 |
| --- | --- | --- |
| 表单输出内容 | 默认包含 `{{form}}` 和提交说明 | 用于展示表单说明和表单内容 |
| 表单配置 | 右侧有 `+ 添加` | 用于添加一个或多个表单项 |
| 输出参数 | `表单全部内容(form_data)` | 表单提交后的整体数据 |

默认表单输出内容：

```text
你好，请先填写下面表单内容：
{{form}}
填写后请点击【提交】按钮进行提交。
```

输出参数：

| 显示名称 | 变量名 | 说明 |
| --- | --- | --- |
| 表单全部内容 | `form_data` | 用户提交的所有表单项数据 |

官方资料补充：

```text
表单全部内容会作为固定输出；各个表单项也会参数化输出。
```

也就是说，如果添加了参数 `attachment_test`，后续节点一般可以直接绑定该字段，而不是只能读整包 `form_data`。

## 3. 添加参数弹窗

点击 `表单配置 -> + 添加` 后，打开“添加参数”弹窗。

弹窗有两个页签：

```text
基本信息
显隐设置
```

### 3.1 基本信息

当前截图中基础字段：

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 参数 | 是 | 英文参数名，下游引用用 |
| 显示名称 | 是 | 用户看到的字段名 |
| 参数提示说明 | 否 | 字段填写提示，最多 128 字符 |
| 是否必填 | 是 | 开关，控制用户是否必须填写 |
| 组件类型 | 是 | 选择具体表单组件 |

注意：

```text
1. 参数名很重要，会成为后续节点引用字段，例如 `attachment_test`。
2. 显示名称是用户看到的名字，例如“附件”。
3. 参数提示说明适合写简短提示，例如“请上传需要测试的附件”。
4. 是否必填只影响表单提交校验，不等同于工作流后端字段是否必填。
```

### 3.2 显隐设置

当前截图中显隐设置包含：

| 配置项 | 说明 |
| --- | --- |
| 显示条件 / 隐藏条件 | 控制当前表单项在什么条件下显示或隐藏 |
| 符合以下 所有 / 任一 条件 | 多条件关系 |
| 条件行 | `请选择变量 / 请选择条件 / 请输入值` |
| 添加 | 添加显隐条件 |

官方更新日志补充：

```text
表单收集节点的参数支持显隐设置。
```

使用建议：

```text
1. 显隐条件适合做“选择 A 后显示字段 B”。
2. 多条件默认优先用“所有”，避免误显示。
3. 条件变量尽量选择同一表单内已填写的字段，或明确的上游变量。
4. 显隐逻辑复杂时，不要全塞表单里，可先用判断器分流到不同表单收集节点。
```

## 9. 文件上传组件

当前截图可见配置：

| 配置项 | 初始状态 / 可见内容 | 说明 |
| --- | --- | --- |
| 单次上传最多文件数 | 示例 `3` | 最多上传几个文件 |
| 每个文件最大(MB) | 示例 `10` | 单文件大小限制 |
| 文件类型 | 示例 `jpg`，可添加后缀名 | 允许上传的后缀 |

项目已实测配置：

| 配置项 | 实测值 |
| --- | --- |
| 参数 | `attachment_test` |
| 显示名称 | `附件` |
| 参数提示说明 | `请上传需要测试的附件` |
| 是否必填 | 开启 |
| 组件类型 | `文件上传` |
| 单次上传最多文件数 | `3` |
| 每个文件最大(MB) | `10` |
| 文件类型 | `jpg/pdf/docx` |

项目已实测输出：

```json
{
  "attachment_test": [
    {
      "name": "xxx.pdf",
      "file_id": "xxx",
      "size": 12345,
      "uid": "xxx",
      "status": "success"
    }
  ]
}
```

已知结论：

```text
1. 表单收集节点可以成功接收上传文件。
2. 下游节点可以通过 `attachment_test` 拿到附件数组。
3. 指定回复不支持 `attachment_test[0].file_id` 这类数组下标取值。
4. 需要用 Python 工具提取 file_id，或直接把附件数组传给工具。
5. 当前环境实测可通过 `/admin/oss/file/{file_id}` 下载 MaxKB 内部附件，但它属于内部路径，不是官方公开稳定 API，禁止跨项目直接照搬。
6. `/chat/api/oss/file` 是上传接口，不是下载接口。
```

业务附件协议示例：

```text
MaxKB 表单收集附件
  -> 导入 MaxKB 附件到业务系统
  -> 生成目标项目需要的附件字段值，例如 `{attachmentId}::{url}::{fileName}`
  -> 合并到业务提交字段
```

注意：

```text
1. 其他环境优先使用目标版本 Swagger、官方公开 API 或公司提供的受控文件代理接口。
2. 内部下载路径可能随版本、权限、部署前缀或反向代理变化，也可能要求管理员权限。
3. 不要把内部 file_id、内部下载地址或长期凭证直接返回给普通用户。
```

```text
不要把表单收集上传得到的 file_id 直接当工作流附件字段值。
业务附件字段值必须转成目标项目自己的协议。
```

## 11. 显隐设置设计建议

显隐设置很适合优化用户体验。

示例：

```text
字段：是否需要上传附件
组件：开关

字段：附件
组件：文件上传
显隐设置：当“是否需要上传附件”为 true 时显示
```

或：

```text
字段：请假类型
组件：单选框

字段：病假证明
组件：文件上传
显隐设置：当“请假类型”等于“病假”时显示
```

建议：

```text
1. 简单显隐放表单收集里。
2. 复杂分支仍交给判断器。
3. 显隐条件不要依赖 AI 对话的长文本回答。
4. 显隐条件优先依赖表单内结构化字段。
```

## 12. 对当前工作流的优化价值

表单收集后续可能优化这些场景：

| 场景 | 价值 |
| --- | --- |
| 附件、图片、文件等组件字段 | 已实测可上传文件，适合作为组件处理子智能体入口 |
| 用户输入很不规范时 | 可把部分字段改成结构化表单，减少 AI 猜测 |
| 缺失字段补全 | 对少量缺失字段可以直接弹表单收集 |
| 可选字段补充 | 用显隐条件控制是否展示附件、备注等可选字段 |
| 测试工具入参 | JSON 文本框、单选、多选、滑块可快速构造结构化输入 |

当前不建议：

```text
1. 用表单收集替代整个动态表单主链路。
2. 在总智能体多个分支重复铺 `附件表单收集 -> 导入MaxKB附件到业务系统`。
3. 把复杂动态字段全部手工配置到表单收集节点。
```

当前更稳方向：

```text
1. 表单收集优先收口到“组件能力测试智能体”或组件处理子智能体。
2. 总智能体通过“智能体节点”调用子智能体。
3. 只在必要时收集附件、图片、明细表等主链路不宜直接处理的字段。
```

## 13. 易错点

```text
1. 参数名写错，导致下游工具取不到字段。
2. 只看 `form_data`，忘记单个表单项也会参数化输出。
3. 文件上传拿到的是 MaxKB 内部 file_id，不是业务附件 ID。
4. 指定回复不支持数组下标取值，例如 `attachment_test[0].file_id`。
5. 文件类型后缀没配全，用户上传失败。
6. 日期格式与工作流字段协议不一致。
7. 可选附件未主动要求时，不应强制进入附件收集。
8. 显隐条件太复杂，导致用户看不到该填字段。
9. 密码框不应用于工作流安全验证，签名/密码/人脸应回小程序处理。
```

## 14. 官方与项目依据

MaxKB 官方文档说明：

```text
表单收集通过表单设计，以引导方式主动获取必要信息，一般用于需要多次询问的应答场景。
表单输出内容用于提示说明以及展示表单内容。
表单配置通过添加不同组件进行表单设计。
输出参数包括表单全部内容 form_data，各表单项也会参数化输出。
```

MaxKB 更新日志说明：

```text
表单收集节点的参数新增显隐设置功能。
表单收集节点的参数配置支持调整参数顺序。
```

通用实测结论：

```text
1. 文件上传组件可返回 name/file_id/size/uid/status。
2. 多附件上传可返回多条附件。
3. MaxKB 内部附件可经后端代理转存到业务系统。
4. 转存后再生成目标项目需要的附件字段值。
```
