# 第 06 篇：MaxKB AI 能力低优先级节点速查
> 文档状态（2026-07-01）：根据空白高级智能体验证截图，记录通用业务链路低频使用的 AI 能力节点基础配置。
> 当前口径：只记录初始配置和输出参数，后续语音、图片、视频能力升级时再深入研究。

## 1. 当前结论

下面这些节点普通工作流主链路暂不需要，只做基础速查：

```text
文本转语音
语音转文本
图片生成
图片理解
视频理解
```

使用原则：

```text
1. 不纳入普通工作流主链路优化范围。
2. 不为这些节点设计复杂业务链路。
3. 只记录“模型、输入、返回内容、输出参数”等基础配置。
4. 后续如果要支持语音输入、图片识别、视频理解，再单独扩展专题。
```

## 2. 文本转语音

节点入口：

```text
基础组件 -> AI 能力 -> 文本转语音
```

当前截图可见配置：

| 配置项 | 初始状态 / 可见内容 | 说明 |
| --- | --- | --- |
| 语音合成模型 | 右侧模型来源为 `自定义`，下方需要选择语音合成模型 | 必填 |
| 选择文本内容 | 下拉占位为 `选择文本内容` | 必填，选择要转成语音的文本 |
| 返回内容 | 开关开启 | 开启后可能把结果返回到对话中 |
| 输出参数 | `结果(result)` | 后续节点可引用 |

通用建议：

```text
1. 暂不接入工作流主链路。
2. 如果后续做无障碍或语音播报，再测试它和指定回复、语音播放的关系。
3. 先不要把工作流申请内容自动转语音，避免泄露审批或个人信息。
```

## 3. 语音转文本

节点入口：

```text
基础组件 -> AI 能力 -> 语音转文本
```

当前截图可见配置：

| 配置项 | 初始状态 / 可见内容 | 说明 |
| --- | --- | --- |
| 语音识别模型 | 右侧模型来源为 `自定义`，下方需要选择语音识别模型 | 必填 |
| 选择语音文件 | 下拉占位为 `请选择语音文件` | 必填，选择要识别的语音文件 |
| 返回内容 | 开关开启 | 开启后可能把识别结果返回到对话中 |
| 输出参数 | `结果(result)` | 后续节点可引用 |

通用建议：

```text
1. 暂不替代 `开始 -> 用户问题(question)`。
2. 如果后续开启基本信息里的语音输入，需要确认语音文件变量从哪里输出。
3. 语音识别结果进入字段解析前，建议先经过“问题优化”或文本规范化节点。
```

## 4. 图片生成

节点入口：

```text
基础组件 -> AI 能力 -> 图片生成
```

当前截图可见配置：

| 配置项 | 初始状态 / 可见内容 | 说明 |
| --- | --- | --- |
| 图片生成模型 | 右侧模型来源为 `自定义`，下方需要选择图片生成模型 | 必填 |
| 提示词（正向） | 默认填入 `{{开始.question}}` | 必填，描述希望生成的内容 |
| 提示词（负向） | 文本框占位为“不想生成的图片内容” | 可选，用于排除不想要的内容 |
| 返回内容 | 开关开启 | 开启后可能返回图片结果 |
| 异常捕获 | 输出参数区右侧可见，默认关闭 | 具体打开后待核对 |
| 输出参数 | `AI 回答内容(answer)`、`图片(image)` | 后续节点可引用 |

通用建议：

```text
1. 当前工作流申请场景不需要图片生成。
2. 不要用图片生成处理审批表单、附件或申请内容。
3. 后续如果做宣传图、通知封面等非审批主链路能力，再单独评估。
```

| 选择图片 | 下拉占位为 `请选择图片` | 必填，选择要识别的图片 |
| 输出思考 | 默认关闭 | 是否输出推理过程待核对 |
| 返回内容 | 开关开启 | 开启后可能返回回答 |
| 异常捕获 | 输出参数区右侧可见，默认关闭 | 具体打开后待核对 |
| 输出参数 | `AI 回答内容(answer)` | 后续节点可引用 |

通用建议：

```text
1. 暂不接入正式工作流主链路。
2. 如果后续识别图片附件内容，必须先评估隐私、安全和准确性。
3. 图片理解不能替代附件上传协议，业务附件仍需走附件转存并生成目标项目自己的附件字段值。
```


## 7. 后续升级再研究的点

```text
1. 基本信息开启文件上传后，图片、音频、视频变量如何传给这些节点。
2. 语音转文本结果能否稳定进入问题优化或意图识别。
3. 图片理解能否用于辅助识别附件类型或图片内容摘要。
4. 视觉/视频节点异常捕获打开后的输出结构。
5. 返回内容关闭后，是否仍可由指定回复读取输出参数。
```
