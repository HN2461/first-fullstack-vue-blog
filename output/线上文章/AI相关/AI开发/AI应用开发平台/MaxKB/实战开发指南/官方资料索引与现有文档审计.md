# 官方资料索引与现有文档审计

> 核验日期：2026-07-19。
>
> 当前官方文档页显示版本 `v2.10.4-lts`；官方 GitHub 最新发布同为 `v2.10.4-lts`，发布时间为 2026-07-16。

## 1. 官方资料优先级

```text
目标环境内“关于”或版本信息
  -> 与该版本匹配的官方文档
  -> 官方 GitHub release / changelog
  -> 官方仓库 v2 分支源码
  -> FIT2CLOUD 官方社区知识库
  -> 普通社区帖子和历史实测
```

官方文档也可能存在同页冲突或更新滞后。遇到冲突时记录两种口径，并在目标环境实测，不自行删掉其中一个证据。

## 3. 关键版本变化

### v2.8.0（2026-04-10）

- 新增工作流工具、Python 工具自动生成、知识库完整元数据导入导出。
- 高级智能体支持用户选择模型和知识库，变量聚合支持 Dict。
- 修复自定义工具沙箱、MCP 配置、`html_rander`、`echarts_rander` 等多项安全漏洞。

### v2.9.0（2026-05-07）

- 新增长期记忆、节点启用/禁用和关联资源查看。
- 变量赋值支持显式 `null`，判断器新增正则和通配符。
- 修复 Webhook 鉴权、知识库引用和多个高级编排问题。

### v2.10.1-lts（2026-06-10）

- 修复带用户输入参数的智能体无法调试、开关默认值和外置参数错误。
- 修复多模态节点变量解析和部分工具依赖问题。

### v2.10.2-lts（2026-06-18）

- 表单文件可在对话日志下载。
- 开场白 `html_rander` 的 `sendMessage` 支持透传接口和用户输入参数。
- 修复执行详情、知识库、登录和工具相关问题。

### v2.10.4-lts（2026-07-16）

- 修复文件权限、跨应用日志、跨知识库越权、API Key、MCP、工作空间模型参数等权限问题。
- 修复提示词注入和 Web 文档导入/同步 SSRF 风险。
- 修复触发器用户输入默认值与开关参数传递等问题。

结论：本资料库中的节点和渲染经验如果来自 `v2.8.0` 之前，必须重新验证；公开链接、API、MCP、自定义工具、文件和 HTML 渲染尤其要先确认版本。

## 4. 现有文档审计结论

### 4.1 可作为核心实战资料继续保留

| 文档组 | 评价 | 使用方式 |
| --- | --- | --- |
| 变量引用与跨环境参数 | 实战价值高，明确区分环境态、用户态、会话态 | 结合目标项目字段映射使用 |
| 逐节点创建手册 | 配置细节丰富，适合搭建时查漏 | 先核对目标版本界面 |
| 功能智能体阶段演进 | 很适合公司环境的稳定版/开发版管理 | 继续作为工程规则 |
| 长链路文档拆分 | 能避免提示词、工具和联调记录混杂 | 继续作为文档治理规则 |
| API 接入规则 | 覆盖公开链接、系统 API 和流式返回 | 每个智能体从概览复制当前 API 信息 |

### 4.2 必须加版本或风险标签的内容

| 内容 | 风险 | 正确口径 |
| --- | --- | --- |
| 无限循环最大次数 | 官方当前同页出现 500/1000 冲突 | 不依赖固定数字，当前环境实测；服务端配置交管理员 |
| `/admin/oss/file/{file_id}` | 内部路径，不是公开稳定 API | 仅当前环境研究，跨项目改用公开 API/代理 |
| `.mk` pickle 结构 | 逆向内部格式，版本可能变化且反序列化有风险 | 只处理可信导出包的复制件，优先手工/官方导入导出 |
| `html_rander`/`echarts_rander` | 历史版本存在 XSS/代码注入修复 | 核对版本，固定模板，转义变量，不承载高风险动作 |
| 发布 URL 传用户 token | URL 可能进入历史、日志和 Referer | 优先安全中转或短期票据，后端重新鉴权 |
| 模型输出思考 | 可能泄露内部指令或敏感上下文 | 正式用户场景默认关闭，按需授权查看 |

### 4.3 已由当前官方资料补齐的旧待核对项

```text
1. 基本信息已包含用户输入、接口传参、会话变量、长期记忆和文件上传。
2. 开始节点可输出 question，以及开启上传后的 document/image/audio/video/other。
3. AI 对话历史上下文可选择节点或工作流口径。
4. AI 对话支持 MCP、工具、Skills、子智能体和异常信息 exception_message。
5. 知识库检索当前输出 paragraph_list、is_hit_handling_method_list、data、directly_return。
6. 智能体导出不包含所选择的知识库与模型绑定，导入后必须重绑。
7. 工具和触发器创建后默认需要启用，工具导入后应复核启动参数和权限。
```

## 5. 后续维护要求

每次公司环境升级后，先回归：

```text
基本信息的用户输入/接口传参/会话变量
开始节点和文件输出变量
AI 节点模型、视觉、技能和异常捕获
判断器、循环、变量赋值 null、变量聚合/拆分
工具、MCP、子智能体和触发器
知识库检索输出与命中结果
公开链接、嵌入代码、API Key 和流式返回
quick_question/html_rander/echarts_rander
.mk/.tool/知识库导入导出
对话日志、执行详情和资源授权
```

升级验证结果应写明“旧版本表现、目标版本表现、是否需要改文档”，不要直接覆盖历史结论。
