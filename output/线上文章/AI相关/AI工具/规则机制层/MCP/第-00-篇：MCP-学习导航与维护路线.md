# 第 00 篇：MCP 学习导航与维护路线

主人，这套目录现在按你要的方式维护成两条主线：

1. 概念与原理：解决面试和架构认知问题
2. 常用 MCP 清单：解决开发落地和快速选型问题

你可以把它理解为：

- 上半区回答“为什么、是什么、边界在哪”
- 下半区回答“用哪个、怎么配、踩坑点是什么”

## 建议阅读顺序

1. 先读 `01-MCP-是什么与开放标准核心认知.md`，建立统一认知
2. 再读 `02-常用-MCP-分类与选型总览.md` 和 `03-前端开发常用-MCP-清单与选型建议（2026-07复核）.md`，快速形成工具地图
3. 准备面试前读 `04` 到 `06` 三组问答
4. 需要复刻环境时再读 `07-谷歌-MCP-配置手册（Windows，Chrome-DevTools-MCP-复刻）.md`

## 维护规则（后续补内容时按这个来）

1. 每篇文章必须有 frontmatter，且 `title` 与正文 H1 语义一致
2. 结论类内容尽量标注“复核日期”，避免过时结论长期悬挂
3. 清单类文章统一用固定字段：定位、场景、接入、优势、局限、面试可讲点
4. 面试题优先写“30 秒回答 + 2 分钟展开”两版话术
5. 踩坑记录必须写“现象、根因、修复、预防”，避免只记录结论
