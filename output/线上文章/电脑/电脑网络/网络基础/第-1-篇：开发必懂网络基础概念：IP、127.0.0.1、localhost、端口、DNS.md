# 第 1 篇：开发必懂网络基础概念：IP、127.0.0.1、localhost、端口、DNS

开发时总看到 `127.0.0.1:3000`、`localhost`、`端口号` 这些东西，它们到底是什么？这篇文章帮你一次性搞清楚。

---

**适合刚开始学习开发的人。** 如果你只是想知道电脑为什么连不上网，可先看 [Windows IP、DNS、网关速查](/console/article-directory/articles/windows-ip-dns-dhcp-fd5c357b)。读本文时，可以先用下面的两分钟练习认识「本机」「地址」「端口」，再读开发场景。

## 一、IP 地址：互联网上的"门牌号"

### 1.1 什么是 IP 地址

IP 地址是给网络接口分配的地址。电脑可以同时有 Wi‑Fi 和网线接口，因此也可能同时有多个地址。在不同的家庭网络中，同一个私网地址也可能重复出现。

- **IPv4**：4 组数字，每组 0-255，如 `192.168.1.1`
- **IPv6**：8 组十六进制，如 `2001:0db8:85a3::8a2e:0370:7334`

日常开发主要接触 IPv4。

### 1.2 几个特殊的 IP 地址

| IP 地址 | 含义 | 使用场景 |
|---------|------|----------|
| `127.0.0.1` | 本机回环地址 | 本地开发测试 |
| `0.0.0.0` | 所有网络接口 | 服务器监听所有 IP |
| `192.168.x.x` | 私网地址（局域网） | 家里/公司内网 |
| `10.x.x.x` | 私网地址（大企业） | 企业内网 |
| `172.16.x.x - 172.31.x.x` | 私网地址 | 企业内网 |

IPv4 私网地址不会在公网路由。家用设备通常由路由器做 NAT 后访问互联网。

## 二、127.0.0.1 与 localhost：本机的两种叫法

### 2.1 127.0.0.1 是什么

`127.0.0.1` 是**本机回环地址**（Loopback Address）。

当你访问 `127.0.0.1` 时：
- 数据包**不离开本机**
- 不经过网卡
- 直接在操作系统内部"绕一圈"回来

就像给自己寄信，信直接送到自己手里。

### 2.2 localhost 是什么

`localhost` 是保留给本机的主机名，通常解析到 IPv4 回环地址 `127.0.0.1` 或 IPv6 回环地址 `::1`。系统解析器和部分应用可以直接识别它。 [RFC 6761 第 6.3 节](https://www.rfc-editor.org/rfc/rfc6761.html#section-6.3)

### 2.3 两者的区别

| 对比项 | 127.0.0.1 | localhost |
|--------|-----------|-----------|
| 类型 | IP 地址 | 主机名 |
| 地址族 | 固定为 IPv4 | 可返回 IPv4 或 IPv6 回环地址 |
| 使用场景 | 验证 IPv4 本机服务 | 访问支持本机名称的服务 |

如果服务只监听一个地址族，`localhost` 和 `127.0.0.1` 有时会表现不同。排查时可以查看服务启动输出，确认它实际监听的地址。

### 2.4 为什么开发要用 127.0.0.1

- 本地调试，不占用公网带宽
- 不需要联网也能测试
- 安全，外部无法访问

## 三、端口：一扇门对应一个服务

### 3.1 什么是端口

IP 地址找到"哪台电脑"，端口找到"电脑上的哪个服务"。

就像大楼地址（IP）+ 门牌号（端口）。

- 端口范围：0 - 65535
- 判断端口占用时，同时看传输协议、监听地址和端口。例如 TCP 3000 与 UDP 3000 可以同时使用。

### 3.2 端口分类

| 范围 | 类型 | 说明 |
|------|------|------|
| 0 - 1023 | 系统端口 | IANA 的端口分配区间，具体绑定权限由操作系统决定 |
| 1024 - 49151 | 注册端口 | 应用程序常用 |
| 49152 - 65535 | 动态端口 | 可用于临时通信，系统实际分配区间可以配置 |

端口分类见 [IANA 服务名称和传输协议端口号注册表](https://www.iana.org/assignments/service-names-port-numbers/service-names-port-numbers.xhtml)。

### 3.3 常用服务默认端口

| 服务 | 默认端口 | 说明 |
|------|----------|------|
| HTTP | 80 | 网页（不加密） |
| HTTPS | 443 | 网页（加密） |
| FTP | 20, 21 | 文件传输 |
| SSH | 22 | 远程登录（Linux） |
| Telnet | 23 | 远程登录（明文，不安全） |
| MySQL | 3306 | 数据库 |
| PostgreSQL | 5432 | 数据库 |
| Redis | 6379 | 缓存数据库 |
| MongoDB | 27017 | 数据库 |
| Node.js 开发服务器 | 3000, 5000, 8080 | 常见开发端口 |

### 3.4 开发中常见的端口写法

```
127.0.0.1:3000    # 本机 3000 端口
localhost:8080    # 本机 8080 端口
0.0.0.0:80        # 监听所有 IP 的 80 端口
:3000             # 简写，通常等同于 0.0.0.0:3000
```

### 3.5 为什么有时候要加端口号

- HTTP 默认 80，访问 `http://example.com` 自动用 80 端口
- 如果服务跑在 3000 端口，必须写成 `http://example.com:3000`
- HTTPS 默认 443，`https://example.com` 自动用 443

## 四、DNS：域名到 IP 的"翻译官"

### 4.1 为什么需要 DNS

人记不住 IP 地址，但能记住域名。

- 域名：`www.baidu.com`
- IP 地址：`110.242.68.66`

DNS（Domain Name System）负责把域名翻译成 IP 地址。

### 4.2 DNS 解析过程（简化版）

```
浏览器输入 www.baidu.com
    ↓
检查浏览器缓存
    ↓
由系统或浏览器检查可用的本地缓存，并按各自的解析策略处理 hosts
    ↓
询问当前使用的 DNS 解析服务，例如路由器、单位或浏览器配置的服务
    ↓
本地 DNS 没有就去问根 DNS → 顶级 DNS → 权威 DNS
    ↓
返回 IP 地址：110.242.68.66
    ↓
浏览器用 IP 建立连接
```

### 4.3 开发中如何利用 hosts 文件

可以**手动指定域名解析**，跳过 DNS：

```
# C:\Windows\System32\drivers\etc\hosts

127.0.0.1    myproject.test
192.168.1.100    test-server.local
```

然后访问 `http://myproject.test` 就会指向本机。

**用途**：
- 本地开发多域名测试
- 屏蔽广告（把广告域名指向 127.0.0.1）
- 内网测试环境

## 五、常见开发场景对照

### 5.1 启动本地开发服务器

```bash
npm run dev
# 输出：Local: http://localhost:5173/
```

这意味着：
- 服务监听在本机 `127.0.0.1` 的 `5173` 端口
- 浏览器访问 `http://localhost:5173` 即可

### 5.2 让局域网其他设备访问

```bash
npm run dev -- --host 0.0.0.0
# 适用于 package.json 的 dev 脚本启动 Vite 的项目
```

- `0.0.0.0` 表示监听所有网络接口
- 同一局域网下，其他设备用你电脑的局域网 IP（如 `192.168.1.50:5173`）访问。仅在需要分享的可信网络中打开，结束后在终端按 `Ctrl + C` 停止。

### 5.3 为什么有时候访问不了

检查清单：

1. 防火墙是否放行该端口
2. 服务是否真的在监听（命令行看输出）
3. IP 和端口是否正确
4. 检查服务是否监听该电脑的局域网地址，或监听所有 IPv4 地址。`127.0.0.1` 只供本机访问。全地址监听前先确认所在网络可信。 [Vite：server.host](https://vite.dev/config/server-options#server-host)

## 六、速查表

| 场景 | 写法 | 含义 |
|------|------|------|
| 本地开发 | `http://localhost:3000` | 本机 3000 端口 |
| 本地开发 | `http://127.0.0.1:3000` | 同上 |
| 局域网访问 | `http://192.168.1.50:3000` | 局域网某台机器 |
| 监听所有 IP | `0.0.0.0:3000` | 本机 + 局域网都可访问 |
| 线上网站 | `https://example.com` | 自动用 443 端口 |
| 自定义域名测试 | `hosts` 文件 | 手动绑定域名到 IP |

## 七、两分钟练习

打开终端，依次运行 `ping -n 1 127.0.0.1` 和 `ping -n 1 localhost`。看到前者显示 `127.0.0.1`、后者显示 `127.0.0.1` 或 `::1` 时，说明它们此次都指向你的电脑。这个测试只检查本机回环，无需修改系统设置。

已有练习项目时，可运行项目自己的开发启动命令，再把终端输出的整个地址复制到浏览器。若终端显示 `http://localhost:5173/`，把地址里的 `localhost` 和端口 `5173` 分别圈出来。
