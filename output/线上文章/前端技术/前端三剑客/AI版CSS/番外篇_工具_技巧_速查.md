## 第21章 CSS 啊哈时刻：那些“原来还可以这样写”的技巧

> 这一章不系统讲理论，而是给你一串容易上手、能立刻改善体验的“小 ah-ha 技巧”。

### 21.1 使用 :is() 简化复杂选择器

当你有多个选择器需要共享一套样式时，过去会这样写：

```css
/* 传统写法：每个选择器都要重复父选择器 */
.card h2,
.card h3,
.card h4 {
  font-weight: 600;      /* 字重600 */
}
```

现在可以用 `:is()` 把它们合在一起：

```css
/* 现代写法：使用:is()伪类函数 */
.card :is(h2, h3, h4) {
  font-weight: 600;      /* 选中.card内的所有h2、h3、h4 */
}

/* 更复杂的示例：多层嵌套时的优势 */
/* 传统写法需要写9个选择器 */
.header h1, .header h2, .header h3,
.article h1, .article h2, .article h3,
.footer h1, .footer h2, .footer h3 {
  color: var(--color-primary);
}

/* 使用:is()只需要一行 */
:is(.header, .article, .footer) :is(h1, h2, h3) {
  color: var(--color-primary);    /* 大幅简化选择器 */
}
```

- 更简洁
- 以后需要新增 `h5` 时，只需要在 :is() 内补一个选择器
- :is() 的特异性由参数中最高的决定


### 21.2 使用 :where() “零特异性”挂载样式

`:where()` 和 `:is()` 类似，但它本身**特异性为 0**，适合用于“不会抢优先级”的全局样式。

示例：

```css
/* 全局默认标题样式，特异性为0 */
:where(h1, h2, h3, h4, h5, h6) {
  font-family: inherit;            /* 继承父元素字体 */
  font-weight: 600;                /* 默认字重600 */
  line-height: 1.3;                /* 紧凑行高 */
  margin-top: 0;                   /* 清除顶部边距 */
}

/* 对比:is()的特异性 */
/* :is()的特异性为(0,1,0) - 一个类选择器 */
:is(.title) {
  color: blue;
}

/* :where()的特异性为(0,0,0) - 零特异性 */
:where(.subtitle) {
  color: gray;
}

/* 后续样式很容易覆盖:where()的规则 */
.article h2 {
  font-weight: 700;                /* 轻松覆盖:where()中的600 */
}

/* 但覆盖:is()需要相同或更高的特异性 */
.page :is(.title) {
  color: red;                      /* 需要更高特异性才能覆盖 */
}
```

> 可以简单理解：`:where()` 适合写"轻轻挂在底层的默认样式"，不会制造特异性地雷。

### 21.3 用 min(), max(), clamp() 控制“聪明的尺寸”

前面我们已经用 `clamp()` 做过自适应字体，这里再总结一下：

- `min(a, b)`：取较小值
- `max(a, b)`：取较大值
- `clamp(min, preferred, max)`：值在 min~max 之间变化

例子：限制一个卡片宽度：

```css
/* 响应式卡片宽度 */
.card {
  /* clamp(最小值, 理想值, 最大值) */
  width: clamp(260px, 50vw, 420px);
  /* 解释：
     - 视口很小时：宽度为260px（最小值）
     - 视口中等时：宽度为50vw（视口宽度的50%）
     - 视口很大时：宽度为420px（最大值）
  */
}

/* 更多实用示例 */
.hero-title {
  /* 响应式字号：28px-5vw-48px */
  font-size: clamp(1.75rem, 5vw, 3rem);
}

.container {
  /* 响应式内边距：16px-5%-64px */
  padding: clamp(16px, 5%, 64px);
}

/* min()和max()的单独使用 */
.sidebar {
  /* 取较小值：300px或30% */
  width: min(300px, 30%);           /* 防止侧边栏太宽 */
}

.button {
  /* 取较大值：确保最小宽度 */
  width: max(120px, 15%);           /* 按钮不会太窄 */
}
```

- 很窄屏时不会低于 260px
- 中间区间按视口宽度 50vw 调整
- 宽屏时不会超过 420px


### 21.4 使用 aspect-ratio 做固定比例盒子

以前想要固定宽高比（比如 16:9 视频盒子），通常要用 padding hack：

```css
/* 传统方法：使用padding-top百分比技巧 */
.video-wrapper {
  position: relative;               /* 相对定位作为参考 */
  padding-top: 56.25%;              /* 9÷16 = 0.5625 = 56.25% */
  /* padding百分比是相对于父元素宽度计算的 */
}

.video-wrapper iframe {
  position: absolute;               /* 绝对定位填满容器 */
  inset: 0;                        /* 等同于top:0 right:0 bottom:0 left:0 */
  width: 100%;                     /* 宽度100% */
  height: 100%;                    /* 高度100% */
}
```

现在可以用更直观的 `aspect-ratio`：

```css
/* 现代方法：直接使用aspect-ratio */
.video {
  width: 100%;                     /* 宽度100% */
  aspect-ratio: 16 / 9;            /* 宽高比16:9 */
  background: #0f172a;             /* 背景色占位 */
}

/* 更多常用比例 */
.square {
  aspect-ratio: 1 / 1;             /* 1:1 正方形 */
}

.portrait {
  aspect-ratio: 3 / 4;             /* 3:4 竖版 */
}

.landscape {
  aspect-ratio: 4 / 3;             /* 4:3 横版 */
}

.cinematic {
  aspect-ratio: 21 / 9;            /* 21:9 超宽屏 */
}

/* 结合max-width限制尺寸 */
.card-image {
  width: 100%;
  max-width: 400px;                /* 最大400px宽 */
  aspect-ratio: 16 / 10;           /* 16:10比例 */
  object-fit: cover;               /* 图片填充方式 */
}
```


### 21.5 用 scroll-margin-* 优化锚点滚动体验

很多页面有"目录 → 滚动到某一节"的交互：

```html
<a href="#section-3">跳到第 3 节</a>
...
<h2 id="section-3">第 3 节标题</h2>
```

如果页面顶部有固定导航栏（fixed header），滚动后标题经常会被遮住。可以在标题上加一个 `scroll-margin-top`：

```css
/* 锚点滚动优化 */
.section-title {
  scroll-margin-top: 80px;         /* 预留出header高度 */
  /* 当点击锚点滚动到此元素时，
     会在视口顶部额外留出80px空间 */
}

/* 更完整的方案：使用CSS变量 */
:root {
  --header-height: 60px;           /* 定义header高度 */
}

.site-header {
  position: fixed;
  top: 0;
  height: var(--header-height);
}

h2[id], h3[id], h4[id] {
  /* 所有带id的标题都预留空间 */
  scroll-margin-top: calc(var(--header-height) + 20px);
  /* header高度 + 20px额外间距 */
}
```

这样浏览器在滚动到锚点时，会自动留出指定距离，改善阅读体验。

### 21.6 用 overscroll-behavior 避免"橡皮筋串页面"

在嵌套滚动容器中（比如一个内部可滚动的对话框），滚到顶部/底部时，外层页面容易继续滚动，造成体验不佳。

可以使用：

```css
/* 模态框滚动隔离 */
.modal-body {
  max-height: 60vh;                /* 最大高度60%视口 */
  overflow-y: auto;                 /* 垂直滚动 */
  overscroll-behavior: contain;    /* 阻止滚动传递 */
  /* contain: 滚动到边界时停止，不影响外层
     auto: 默认行为，会传递给父元素
     none: 完全禁用过度滚动效果 */
}

/* 移动端下拉刷新控制 */
html {
  /* 禁用浏览器的下拉刷新 */
  overscroll-behavior-y: none;
}

/* 侧边栏滚动隔离 */
.sidebar {
  height: 100vh;
  overflow-y: auto;
  /* x轴禁用，y轴隔离 */
  overscroll-behavior: none contain;
}
```

- 当用户在 `modal-body` 内滚动到顶/底时，不会把滚动传递给外层页面

### 21.7 用 pointer-events 控制点击穿透

有时需要一个"只展示不挡点击"的装饰层，比如一个大范围的渐变覆盖或高亮遮罩。

```css
/* 装饰性遮罩层 */
.highlight-overlay {
  position: absolute;
  inset: 0;                         /* 填满父容器 */
  /* 径向渐变装饰 */
  background: radial-gradient(
    circle at 0% 0%, 
    rgba(56, 189, 248, .2), 
    transparent
  );
  pointer-events: none;             /* 鼠标事件穿透 */
  /* none: 完全穿透，不响应任何鼠标事件
     auto: 默认，正常响应
     其他值用于SVG */
}

/* 禁用状态的覆盖层 */
.disabled-overlay {
  position: absolute;
  inset: 0;
  background: rgba(0, 0, 0, 0.5);
  pointer-events: auto;             /* 阻止点击下层元素 */
  cursor: not-allowed;              /* 显示禁用光标 */
}

/* 条件性交互 */
.interactive-layer {
  pointer-events: none;             /* 默认穿透 */
}

.interactive-layer.active {
  pointer-events: auto;             /* 激活时可交互 */
}
```

- `pointer-events: none;` 让鼠标事件"穿透"这个层，下面的按钮仍然可点击

### 21.8 用 mix-blend-mode 做文字高亮效果

在深色背景中想做某种"发光"式文字，可以试试：

```css
/* 基础混合模式效果 */
.glow-text {
  color: #e5e7eb;
  mix-blend-mode: screen;           /* 滤色模式 */
  /* 常用混合模式：
     normal: 正常（默认）
     multiply: 正片叠底（变暗）
     screen: 滤色（变亮）
     overlay: 叠加
     difference: 差值
     exclusion: 排除
  */
}

/* 创意文字效果 */
.hero-title {
  font-size: 5rem;
  font-weight: 900;
  color: white;
  mix-blend-mode: difference;      /* 反色效果 */
}

/* 配合背景使用 */
.blend-section {
  background: linear-gradient(135deg, #667eea, #764ba2);
}

.blend-section h2 {
  color: white;
  mix-blend-mode: overlay;         /* 与背景融合 */
  text-shadow: 0 2px 10px rgba(0,0,0,0.3);
}

/* 注意：需要考虑可读性 */
.readable-blend {
  mix-blend-mode: screen;
  /* 添加文字阴影增强可读性 */
  text-shadow: 0 0 20px rgba(0,0,0,0.5);
}
```

配合背后的渐变背景，可以产生有趣的融合效果（注意可读性和对比度）。

### 21.9 用子网格（subgrid）（前瞻概念）统一对齐

部分现代浏览器开始支持 `subgrid`：

```css
/* 父网格定义 */
.article-layout {
  display: grid;
  /* 三列：侧边空白 - 内容 - 侧边空白 */
  grid-template-columns: 1fr min(720px, 100%) 1fr;
  gap: 20px;
}

/* 子元素继承父网格轨道 */
.article-body {
  display: grid;
  grid-column: 2;                  /* 占据第二列 */
  grid-template-columns: subgrid;  /* 继承父网格的列定义 */
  /* 子元素会沿用父网格的对齐线 */
}

/* 实际应用：卡片对齐 */
.card-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

.card {
  display: grid;
  grid-template-rows: auto 1fr auto; /* 标题-内容-按钮 */
}

/* 使用subgrid让所有卡片的元素对齐 */
.card-aligned {
  display: grid;
  grid-template-rows: subgrid;     /* 行高度统一 */
  grid-row: span 3;                 /* 跨越3行 */
}
```

- 子元素可以继承父网格的轨道，实现复杂但统一的对齐布局
- 目前兼容性还在逐步推进中，做项目时需要根据目标浏览器评估

> 这一节只是提前种一个“前瞻”概念：未来 CSS 布局会更强大、更系统。

## 第22章 CSS 常见迷惑行为解释

> 这一章是“FAQ”风格，集中回答一些 CSS 小白和进阶开发者都会遇到的 WTF：
> - 为什么 margin 会莫名其妙“折叠”？

> - 为什么 flex 子项有时会“挤爆”容器？

### 22.1 外边距折叠：为什么两个盒子之间不是 20px？

场景：

```css
.box-a { margin-bottom: 20px; }
.box-b { margin-top: 20px; }
```

很多人以为两个盒子之间的距离是 40px，实际上往往只有 20px。

原因：

- 垂直方向上相邻块级盒子的 margin 有“折叠规则”
- 简化理解：**上下 margin 取最大值，而不是相加**

简单图示：

```txt
期望：20px + 20px = 40px

实际：

┌──── box-a ────┐
│                │
└────────────────┘
   ↑ 20px margin-bottom
   ↓ 20px margin-top （与上面的折叠）
┌──── box-b ────┐
│                │
└────────────────┘

距离 = max(20, 20) = 20px
```

常用解决方法：

- 改用 `padding` 控制父容器的内边距
- 给其中一个盒子包一层，不让 margin 直接相邻


### 22.2 行内元素的宽高：为什么不听话？

场景：

```css
span {
  width: 200px;
  height: 100px;
  background: #fee2e2;
}
```

发现：`span` 看起来没按宽高变大。

原因：

- `span` 默认是 `display: inline;`
- 行内元素不会响应 `width`/`height`，尺寸由内容和字体决定

解决：

- 改为 `inline-block` 或 `block`

```css
span {
  display: inline-block;
  width: 200px;
  height: 100px;
}
```


### 22.3 flex 子项为什么会“挤爆”或“缩得很奇怪”？

场景：

```css
.row {
  display: flex;
}

.col {
  flex: 1;
}
```

有时子项内容太多，会挤到容器外面；有时又被压扁得看不懂。

关键点：

- `flex: 1` 相当于 `flex: 1 1 0`（grow = 1, shrink = 1, basis = 0）
- `flex-basis: 0` 表示“按可用空间重新分配”，忽略内容宽度

如果你更希望“尊重内容宽度，再适度缩放”，可以用：

```css
.col {
  flex: 1 1 auto;
}
```

或者为内容非常多的列设置 `min-width`，避免被压缩得不可用。


### 22.4 行高与垂直居中的谜团

场景：

```css
.tag {
  display: inline-block;
  line-height: 32px;
  height: 32px;
}
```

有时文字看起来偏上或偏下。

原因：

- 字体本身有上/下“预留空间”（ascent/descent）
- 不同字体、字号下，`line-height = height` 并不意味视觉完美居中

实战建议：

- 对于 tag/badge 一类小组件，用 `line-height` 做垂直居中是简单方案，但要配合具体字体微调
- 更稳定的方式：使用 flex 居中

```css
.tag {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  height: 32px;
}
```


### 22.5 为什么 position: sticky 有时“不吸顶”？

`position: sticky` 可以让元素在滚动到一定位置后“粘住”，但经常有人发现它不生效。

常见原因：

- 没有设置 `top`/`bottom` 等偏移值
- 祖先元素设置了 `overflow: hidden/auto/scroll`，截断了 sticky 的滚动参考

简单示例：

```css
.toc {
  position: sticky;
  top: 80px;  /* 必须给 */
}
```

> Sticky 是“相对最近的可滚动祖先”起作用的，如果你的布局里有中间一层容器设置了 overflow，sticky 就只在那个容器内部生效。


### 22.6 为什么 transform 会影响 position: fixed？

当某个祖先元素设置了 `transform`（比如 `transform: translateY(0);`），在它内部的 `position: fixed` 元素，会变成“相对该祖先固定”，而不是相对视口。

原因：

- transform 等属性会创建新的包含块（containing block）

如果你想让 fixed 元素始终相对视口固定，尽量避免在它的祖先上随意设置 transform。

### 23.1 按钮样式集合

#### 23.1.1 主按钮 + 次按钮 + 幽灵按钮

```css
/* 按钮基础样式 */
.btn {
  /* 布局 */
  display: inline-flex;              /* 行内弹性容器 */
  align-items: center;               /* 垂直居中 */
  justify-content: center;           /* 水平居中 */
  gap: 0.4em;                       /* 图标与文字间距 */
  
  /* 尺寸 */
  padding: 0.6em 1.4em;             /* 上下0.6em，左右1.4em */
  
  /* 视觉 */
  border-radius: 999px;             /* 完全圆角（胶囊形） */
  border: 1px solid transparent;    /* 透明边框占位 */
  
  /* 字体 */
  font-size: 0.95rem;               /* 15.2px */
  font-weight: 500;                 /* 中等粗细 */
  
  /* 交互 */
  cursor: pointer;                  /* 手型光标 */
  
  /* 过渡动画：背景色、阴影、位移 */
  transition: background-color 0.15s ease, 
              box-shadow 0.15s ease,
              transform 0.12s ease;
  
  /* 防止文字选中 */
  user-select: none;
}

/* 主按钮样式 */
.btn--primary {
  background: #2563eb;              /* 蓝色背景 */
  color: #ffffff;                   /* 白色文字 */
  /* 初始阴影：向下8px，模糊24px */
  box-shadow: 0 8px 24px rgba(37, 99, 235, 0.45);
}

.btn--primary:hover {
  background: #1d4ed8;              /* 深一度的蓝色 */
  /* 增强阴影：向下12px，模糊32px，透明度更高 */
  box-shadow: 0 12px 32px rgba(37, 99, 235, 0.6);
  transform: translateY(-1px);      /* 轻微上浮效果 */
}

.btn--primary:active {
  transform: translateY(0);         /* 按下时回到原位 */
  box-shadow: 0 4px 16px rgba(37, 99, 235, 0.4);
}

/* 次要按钮 */
.btn--secondary {
  background: #e5e7eb;              /* 浅灰背景 */
  color: #111827;                   /* 深色文字 */
}

.btn--secondary:hover {
  background: #d1d5db;              /* 深一度的灰色 */
}

/* 幽灵按钮（透明背景） */
.btn--ghost {
  background: transparent;           /* 透明背景 */
  color: #2563eb;                   /* 蓝色文字 */
  border-color: rgba(37, 99, 235, 0.5); /* 半透明蓝色边框 */
}
```

#### 23.3.2 自适应卡片网格

```css
/* 自适应卡片网格 */
.card-grid {
  display: grid;
  /* auto-fit: 自动填充可用空间
     minmax(220px, 1fr): 最小220px，最大1fr */
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 20px;                               /* 网格间距 */
  
  /* 可选：添加内边距 */
  padding: 20px;
}

/* 控制最大列数的变体 */
.card-grid--max-4 {
  /* 最多4列，每列最小220px */
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  max-width: 1200px;                      /* 限制最大宽度 */
  margin: 0 auto;                          /* 居中 */
}

/* 固定列数的变体 */
.card-grid--fixed {
  /* 桌面3列，平板2列，手机1列 */
  grid-template-columns: repeat(3, 1fr);
}

@media (max-width: 768px) {
  .card-grid--fixed {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media (max-width: 480px) {

    grid-template-columns: 1fr;
  }
```

- auto-fit会拉伸项目填满空间，auto-fill则保持项目宽度

## 第24章 CSS 全属性速查表（出版附录级）

> 本章不会按字母顺序列出所有属性，而是按主题分类，帮助你快速回忆“我要改 X，该查哪几个属性”。

### 24.1 布局相关

- 布局模型
  - `display`（block / inline / inline-block / flex / grid / inline-flex / inline-grid）
  - `position`（static / relative / absolute / fixed / sticky）
  - `float`、`clear`

- 盒子尺寸与定位
  - `width`、`min-width`、`max-width`
  - `height`、`min-height`、`max-height`
  - `top`、`right`、`bottom`、`left`
  - `box-sizing`

- 外边距与内边距
  - `margin`、`margin-top/right/bottom/left`
  - `padding`、`padding-top/right/bottom/left`

- Flex 布局
  - 容器：`flex-direction`、`flex-wrap`、`justify-content`、`align-items`、`align-content`、`gap`
  - 子项：`flex`、`flex-grow`、`flex-shrink`、`flex-basis`、`align-self`

- Grid 布局
  - 容器：`grid-template-columns`、`grid-template-rows`、`grid-template-areas`、`grid-auto-flow`、`gap`
  - 轨道函数：`repeat()`、`minmax()`、`auto-fit`、`auto-fill`

  - `box-shadow`

- 颜色与透明度
  - 颜色表示法：`rgb()`、`rgba()`、`hsl()`、`hsla()`、十六进制
