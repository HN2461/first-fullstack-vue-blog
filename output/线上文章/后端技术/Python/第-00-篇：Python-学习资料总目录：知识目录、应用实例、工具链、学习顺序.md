# 第 00 篇：Python 学习资料总目录：知识目录、应用实例、工具链、学习顺序

这个目录用于收纳 Python 学习资料，先把基础概念和应用实例分开，后续再逐步补工程化、项目实战和面试复盘。

## 01-知识目录

放基础概念类内容。

当前已经整理：

- Python 零基础入门 01-29
- 变量、字符串、数字、输入、条件判断、循环
- 列表、元组、集合、字典
- 函数、文件读写、异常处理
- 模块、包、pip、虚拟环境、面向对象
- 标准库、csv、logging、迭代器生成器、装饰器、编码、pytest、正则和命令行参数

这部分是“先把语言本身学会”，不要急着上框架。后续如果继续补基础知识，可以放：

- Python 进阶语法
- 正则表达式
- 日期时间处理
- JSON / CSV / Excel 文件处理
- 命令行脚本
- 单元测试基础

## 02-应用实例

放能动手做出来的应用方向。

当前先分两类：

- 网络爬虫与数据分析：请求网页、解析 HTML、保存 CSV、用 pandas 做统计。
- Web 入门：用 Flask / FastAPI 做接口，理解后端项目怎么接收请求、返回数据，并逐步过渡到公司项目开发。

这部分不是为了追求大项目，而是为了把基础知识接到真实场景里。比如：

- 字符串：清洗标题、标签、链接。
- 列表和字典：保存一组数据记录。
- 文件读写：把结果保存成 CSV / JSON。
- 异常处理：处理网络失败、解析失败、文件不存在。
- 模块和虚拟环境：安装 requests、beautifulsoup4、pandas、flask、fastapi。

## 03-工具链与工程化

放项目开发习惯和环境管理内容。

后续可以补：

- 虚拟环境与依赖文件
- pip / uv / poetry 的区别
- 项目目录结构
- 配置文件与环境变量
- 多模块日志配置与集中采集
- 单元测试 pytest
- 代码格式化和 lint

## 建议学习顺序

1. 先读完 `知识目录` 的零基础入门文章。
2. 再做 `网络爬虫与数据分析`，因为它主要用基础语法、文件、异常和第三方库。
3. 再做 `Web入门`，理解 Python 怎么写后端接口。
4. 最后补 `03-工具链与工程化`，把脚本式学习逐步过渡到项目式开发。

## 命名约定

文章文件继续使用编号开头，便于知识库导入后排序。

应用文章不强行和零基础编号混在一起，因为它们属于不同学习阶段。比如：

- `网络爬虫与数据分析/第-1-篇：Python-网络爬虫基础概念：URL、HTTP、robots.txt、HTML、解析、数据保存.md`
- `网络爬虫与数据分析/第-2-篇：requests-请求体系与-robots.txt：方法、参数、Header、Session、异常处理.md`
- `网络爬虫与数据分析/第-3-篇：XPath-解析-HTML-并保存-CSV：lxml、文本提取、属性筛选、urljoin.md`
- `Web入门/第-00-篇：FastAPI-从-0-到-1-学习总目录：路线、章节、项目实战、交付清单.md`
- `Web入门/第-15-篇：企业知识库-API-综合实战：审核流、状态机、权限依赖、事务测试.md`

FastAPI 系统学习入口：

- `Web入门/第-00-篇：FastAPI-从-0-到-1-学习总目录：路线、章节、项目实战、交付清单.md`

这套专题面向已经学完 Python 基础、准备系统深耕 FastAPI 的学习者，共 18 篇，按以下阶段推进：

1. HTTP、ASGI、路由、请求参数、Pydantic 与 OpenAPI。
2. 依赖注入、中间件、生命周期、配置和工程目录。
3. SQLAlchemy、Alembic、CRUD、事务、关联、分页和并发控制。
4. JWT、刷新令牌、RBAC、对象级权限和安全基线。
5. 文件、HTTPX、Redis、缓存、限流、幂等、异步与任务队列。
6. pytest、日志监控、性能、Docker、CI/CD、发布回滚和企业综合实战。

`Web入门` 目录只保留这一套 FastAPI 系统专题，学习时直接进入专题总目录并按 `00–14` 的编号顺序阅读，不再维护重复的框架速览文章。
