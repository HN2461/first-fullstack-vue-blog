# JavaScript 时间戳完全指南

> 一次搞懂时间戳，再也不混乱！🕐

## 一、什么是时间戳？

### 1.1 通俗解释
**时间戳**：从 **1970年1月1日 00:00:00 UTC** 到现在经过的时间

就像一个计时器，从1970年开始计数，每过1秒（或1毫秒）就+1。

```
想象成：
1970年1月1日 = 起跑线（0米）
现在 = 你跑了多少米（时间戳）
```

### 1.2 为什么是1970年？
这是计算机的"元年"，叫做 **Unix纪元**（Unix Epoch）。
所有编程语言都统一用这个标准，方便全球交流。

### 1.3 时间戳的两种单位

| 类型 | 说明 | 长度 | 示例 |
|-----|------|------|------|
| **秒时间戳** | 从1970年到现在的秒数 | 10位 | `1700123456` |
| **毫秒时间戳** | 从1970年到现在的毫秒数 | 13位 | `1700123456789` |

```javascript
// 🔴 最容易搞混的点：
秒时间戳 = 10位数字  // 后端常用（PHP、Python、Java等）
毫秒时间戳 = 13位数字 // 前端常用（JavaScript）

// JavaScript默认用毫秒！！！记住这个！
```

## 二、如何获取时间戳

### 2.1 获取当前时间戳（3种方法）

```javascript
// 方法1：Date.now() - 最简单最常用 ⭐⭐⭐⭐⭐
const timestamp = Date.now();
console.log(timestamp); // 1700123456789（13位毫秒）

// 方法2：new Date().getTime()
const timestamp2 = new Date().getTime();
console.log(timestamp2); // 1700123456789（13位毫秒）

// 方法3：+new Date() - 简写技巧
const timestamp3 = +new Date();
console.log(timestamp3); // 1700123456789（13位毫秒）

// 💡 推荐用 Date.now()，最清晰！
```

### 2.2 获取指定时间的时间戳

```javascript
// 字符串转时间戳
const time1 = new Date('2024-11-16').getTime();
const time2 = new Date('2024-11-16 18:30:00').getTime();
const time3 = new Date('2024/11/16 18:30:00').getTime();

// ⚠️ 注意：Safari浏览器不支持 '2024-11-16 18:30:00' 格式
// 推荐用斜杠：'2024/11/16 18:30:00' 或 ISO格式
const safariOk = new Date('2024/11/16 18:30:00').getTime(); // ✅ 兼容
const isoFormat = new Date('2024-11-16T18:30:00').getTime(); // ✅ 兼容

// 从年月日时分秒创建
const customTime = new Date(2024, 10, 16, 18, 30, 0).getTime();
// ⚠️ 月份从0开始！10代表11月！这是个大坑！
```

### 2.3 秒时间戳 ↔ 毫秒时间戳转换

```javascript
// 毫秒 → 秒（÷1000）
const msTimestamp = Date.now();           // 1700123456789
const sTimestamp = Math.floor(Date.now() / 1000); // 1700123456

// 秒 → 毫秒（×1000）
const secondsFromBackend = 1700123456;    // 后端返回的秒时间戳
const milliseconds = secondsFromBackend * 1000; // 1700123456000

// 💡 记忆技巧：
// JavaScript用毫秒，后端大多用秒
// 前端 → 后端：÷1000
// 后端 → 前端：×1000
```

## 三、时间戳转日期格式

### 3.1 基础转换（原生方法）

```javascript
const timestamp = 1700123456789;
const date = new Date(timestamp);

// 获取各部分
date.getFullYear();  // 2023 - 年份
date.getMonth();     // 10 - 月份（0-11，所以要+1！）
date.getDate();      // 16 - 日期
date.getHours();     // 18 - 小时
date.getMinutes();   // 30 - 分钟
date.getSeconds();   // 56 - 秒
date.getDay();       // 4 - 星期几（0是周日，1是周一...）

// ⚠️ 大坑：getMonth() 返回 0-11，记得 +1！
console.log(date.getMonth() + 1); // 正确的月份
```

### 3.2 手写格式化函数（通用）

```javascript
/**
 * 时间戳格式化
 * @param {number} timestamp - 时间戳（秒或毫秒都行，自动识别）
 * @param {string} format - 格式：'YYYY-MM-DD HH:mm:ss'
 */
function formatTimestamp(timestamp, format = 'YYYY-MM-DD HH:mm:ss') {
  // 自动识别秒/毫秒时间戳
  if (timestamp.toString().length === 10) {
    timestamp = timestamp * 1000; // 秒转毫秒
  }
  
  const date = new Date(timestamp);
  
  const year = date.getFullYear();
  const month = String(date.getMonth() + 1).padStart(2, '0'); // 补0
  const day = String(date.getDate()).padStart(2, '0');
  const hour = String(date.getHours()).padStart(2, '0');
  const minute = String(date.getMinutes()).padStart(2, '0');
  const second = String(date.getSeconds()).padStart(2, '0');
  
  // 替换格式
  return format
    .replace('YYYY', year)
    .replace('MM', month)
    .replace('DD', day)
    .replace('HH', hour)
    .replace('mm', minute)
    .replace('ss', second);
}

// 使用示例
formatTimestamp(1700123456789);                    // '2023-11-16 18:30:56'
formatTimestamp(1700123456);                       // '2023-11-16 18:30:56'（自动识别秒）
formatTimestamp(1700123456789, 'YYYY/MM/DD');     // '2023/11/16'
formatTimestamp(1700123456789, 'YYYY年MM月DD日'); // '2023年11月16日'
formatTimestamp(1700123456789, 'MM-DD HH:mm');    // '11-16 18:30'
```

### 3.3 使用 Day.js 库（推荐）⭐

```javascript
// 1. 安装：npm install dayjs

// 2. 使用
import dayjs from 'dayjs';

// 格式化时间戳
dayjs(1700123456789).format('YYYY-MM-DD HH:mm:ss'); // '2023-11-16 18:30:56'
dayjs(1700123456789).format('YYYY/MM/DD');          // '2023/11/16'
dayjs(1700123456789).format('MM月DD日 HH:mm');      // '11月16日 18:30'

// 秒时间戳也可以（需要 ×1000 或用 unix() 方法）
dayjs.unix(1700123456).format('YYYY-MM-DD');        // '2023-11-16'

// 💡 Day.js 只有 2KB，比 Moment.js 小很多，强烈推荐！
```

## 四、日期格式转时间戳

### 4.1 字符串转时间戳

```javascript
// 常见格式
new Date('2024-11-16').getTime();              // ✅ 推荐

  return new Date(dateStr.replace(/-/g, '/')).getTime();
}

parseDate('2024-11-16 18:30:00'); // 完美兼容
```

## 五、时间计算

### 5.1 计算时间差

```javascript
// 计算两个时间戳的差值
const start = new Date('2024/11/16 09:00:00').getTime();
const end = new Date('2024/11/16 18:00:00').getTime();

const diff = end - start; // 毫秒差

// 转换为各种单位
const diffSeconds = Math.floor(diff / 1000);           // 秒
const diffMinutes = Math.floor(diff / 1000 / 60);      // 分钟
const diffHours = Math.floor(diff / 1000 / 60 / 60);   // 小时
const diffDays = Math.floor(diff / 1000 / 60 / 60 / 24); // 天

console.log(`相差 ${diffHours} 小时`); // 相差 9 小时

// 💡 记忆：
// 1秒 = 1000毫秒
// 1分钟 = 60秒
// 1小时 = 60分钟
// 1天 = 24小时
```

### 5.2 实用工具函数

```javascript
// 判断是否是今天
function isToday(timestamp) {
  const date = new Date(timestamp);
  const today = new Date();
  return date.toDateString() === today.toDateString();
}

// 判断是否是昨天
function isYesterday(timestamp) {
  const date = new Date(timestamp);
  const yesterday = new Date();
  yesterday.setDate(yesterday.getDate() - 1);
  return date.toDateString() === yesterday.toDateString();
}

// 获取几天前/后的时间戳
function getDaysAgo(days) {
  return Date.now() - days * 24 * 60 * 60 * 1000;
}

function getDaysLater(days) {
  return Date.now() + days * 24 * 60 * 60 * 1000;
}

// 使用
isToday(Date.now());           // true
isYesterday(getDaysAgo(1));    // true
getDaysAgo(7);                 // 7天前的时间戳
getDaysLater(7);               // 7天后的时间戳
```

### 5.3 倒计时实现

```javascript
/**
 * 倒计时
 * @param {number} endTimestamp - 结束时间戳
 */
function countdown(endTimestamp) {
  const now = Date.now();
  const diff = endTimestamp - now;
  
  if (diff <= 0) {
    return '已结束';
  }
  
  const days = Math.floor(diff / (1000 * 60 * 60 * 24));
  const hours = Math.floor((diff % (1000 * 60 * 60 * 24)) / (1000 * 60 * 60));
  const minutes = Math.floor((diff % (1000 * 60 * 60)) / (1000 * 60));
  const seconds = Math.floor((diff % (1000 * 60)) / 1000);
  
  return `${days}天 ${hours}小时 ${minutes}分钟 ${seconds}秒`;
}

// 使用
const endTime = new Date('2024/12/31 23:59:59').getTime();
setInterval(() => {
  console.log(countdown(endTime));
}, 1000);
```

## 六、常见场景实战

### 6.1 显示"刚刚"、"3分钟前"等

```javascript
function timeAgo(timestamp) {
  // 自动识别秒/毫秒
  if (timestamp.toString().length === 10) {
    timestamp = timestamp * 1000;
  }
  
  const now = Date.now();
  const diff = now - timestamp;
  
  const second = 1000;
  const minute = second * 60;
  const hour = minute * 60;
  const day = hour * 24;
  const month = day * 30;
  const year = day * 365;
  
  if (diff < minute) {
    return '刚刚';
  } else if (diff < hour) {
    return Math.floor(diff / minute) + '分钟前';
  } else if (diff < day) {
    return Math.floor(diff / hour) + '小时前';
  } else if (diff < day * 2) {
    return '昨天';
  } else if (diff < month) {
    return Math.floor(diff / day) + '天前';
  } else if (diff < year) {
    return Math.floor(diff / month) + '个月前';
  } else {
    return Math.floor(diff / year) + '年前';
  }
}

// 使用
timeAgo(Date.now() - 30000);      // '刚刚'
timeAgo(Date.now() - 300000);     // '5分钟前'
timeAgo(Date.now() - 7200000);    // '2小时前'
```

## 七、常见坑点总结 ⚠️

### 坑点1：秒和毫秒搞混

```javascript
// ❌ 后端返回秒，前端直接用
const timestamp = 1700123456; // 10位秒
new Date(timestamp); // 显示1970年！错了！

// ✅ 正确：先转毫秒
new Date(timestamp * 1000); // 2023年，对了！
```

### 坑点2：月份从0开始

```javascript
// ❌ 错误
new Date(2024, 11, 16); // 这是2024年12月16日，不是11月！

// ✅ 正确
new Date(2024, 10, 16); // 2024年11月16日（月份要-1）

// 获取月份也要+1
const date = new Date();
console.log(date.getMonth() + 1); // 正确的月份
```

### 坑点3：Safari浏览器兼容性

```javascript
// ❌ Safari 不支持
new Date('2024-11-16 18:30:00'); // Safari报错！

// ✅ 兼容写法
new Date('2024/11/16 18:30:00');        // 用斜杠
new Date('2024-11-16T18:30:00');        // ISO格式
new Date('2024-11-16 18:30:00'.replace(/-/g, '/')); // 替换
```

### 坑点4：时区问题

```javascript
// 时间戳是UTC时间（零时区）
// 但 new Date() 会转成本地时区

const timestamp = 1700123456000;
const date = new Date(timestamp);

date.toString();     // 本地时区时间
date.toUTCString();  // UTC时间

// 如果后端给的是UTC时间字符串
const utcStr = '2024-11-16T10:30:00Z'; // 注意有Z
new Date(utcStr).getTime(); // 自动转本地时区的时间戳
```

### 坑点5：取整问题

```javascript
// ❌ 毫秒转秒，不取整
const seconds = Date.now() / 1000; // 1700123456.789（有小数！）

// ✅ 要向下取整
const seconds = Math.floor(Date.now() / 1000); // 1700123456（整数）
```

```javascript
// ===== 工具函数合集 =====

// 1. 时间戳格式化（自动识别秒/毫秒）
function formatTime(timestamp, format = 'YYYY-MM-DD HH:mm:ss') {
  if (timestamp.toString().length === 10) timestamp *= 1000;
  const d = new Date(timestamp);
  const opt = {
    'YYYY': d.getFullYear(),
    'MM': String(d.getMonth() + 1).padStart(2, '0'),
    'DD': String(d.getDate()).padStart(2, '0'),
    'HH': String(d.getHours()).padStart(2, '0'),
    'mm': String(d.getMinutes()).padStart(2, '0'),
    'ss': String(d.getSeconds()).padStart(2, '0')
  };
  return Object.keys(opt).reduce((str, key) => 
    str.replace(key, opt[key]), format);
}

// 2. 获取今天0点时间戳
function getTodayStart() {
  const today = new Date();
  today.setHours(0, 0, 0, 0);
  return today.getTime();
}

// 3. 获取今天23:59:59时间戳
function getTodayEnd() {
  const today = new Date();
  today.setHours(23, 59, 59, 999);
  return today.getTime();
}

// 4. 判断是否同一天
function isSameDay(timestamp1, timestamp2) {
  const d1 = new Date(timestamp1);
  const d2 = new Date(timestamp2);
  return d1.getFullYear() === d2.getFullYear() &&
         d1.getMonth() === d2.getMonth() &&
         d1.getDate() === d2.getDate();
}

// 5. 获取星期几（中文）
function getWeekDay(timestamp) {
  const weekDays = ['日', '一', '二', '三', '四', '五', '六'];
  return '星期' + weekDays[new Date(timestamp).getDay()];
}

// 6. 安全的日期解析（兼容Safari）
function safeParseDate(dateStr) {
  return new Date(dateStr.replace(/-/g, '/')).getTime();
}
```
