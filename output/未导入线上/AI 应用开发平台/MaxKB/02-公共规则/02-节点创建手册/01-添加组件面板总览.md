# 01-添加组件面板总览

> 文档状态（2026-07-01）：根据空白高级智能体验证截图，记录添加组件面板的三个页签和可见节点。

## 1. 面板定位

在高级智能体画布中，点击节点右侧的 `+` 或画布添加入口，会打开添加组件面板。

当前截图中添加组件面板分为三个页签：

```text
基础组件
工具
智能体
```

使用原则：

```text
1. 基础组件是 MaxKB 内置节点能力，例如 AI 对话、判断器、变量赋值、指定回复。
2. 工具页签展示当前系统中已创建的工具，包含业务自定义 Python 工具。
3. 智能体页签展示当前系统中已创建或已发布的智能体，可作为子智能体调用。
4. 本文只记录添加面板里能看到什么，不提前认定每个节点的配置项；具体配置等点进节点后逐个补。
```

工具页签使用注意：

```text
1. 从工具页签添加的是“工具节点”，节点入参需要在画布节点里绑定。
2. 工具名称被省略号截断时，不要凭猜测写文档，必须点开后确认完整名称。
3. 同一个工具可以在不同链路复制多个节点，但每个节点的入参绑定可能不同。
4. 工具的环境参数优先绑定接口传参，例如 `businessBaseUrl`、`agentBaseUrl`、`userTicket`。
```

智能体页签使用注意：

```text
1. 从智能体页签添加的是“智能体节点”，用于调用另一个智能体。
2. 适合把附件、图片、明细表等复杂组件能力收口到子智能体。
3. 正式接入前必须确认子智能体输入参数和返回内容，不要只按名称判断用途。
4. 同名或相似名称智能体很多，点选前必须看完整名称、创建时间和描述。
```
