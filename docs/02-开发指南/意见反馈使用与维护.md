# 意见反馈使用与维护

## 使用入口

- 注册用户：知识库下的「意见反馈」，路径 `/console/feedback`。右上角用户下拉菜单也提供提交入口，可保留发起反馈时的控制台页面路径。
- 超级管理员：后台管理 → 互动运营 → 反馈管理，路径 `/console/manage/feedback`。
- 其他协助处理人：通过角色管理显式授予「反馈管理」菜单；仅有普通管理员身份不会自动获得读取全部反馈的权限。

提交者只能在个人入口查看本人的反馈。获授权处理人可以在管理入口查看和处理全部反馈。菜单显示与授权由数据库 RBAC 决定，不依赖项目讨论权限。

## 提交与处理

反馈类型包含问题 / Bug、功能建议和使用咨询 / 其他。填写标题和正文，可以选择或粘贴 PNG、JPG、WEBP、GIF 图片；每次最多 5 张、每张不超过 5MB。图片与文字随同一请求提交，失败保留输入，重试使用相同提交标识避免重复记录。浏览器信息默认不采集，用户勾选后附带可见的浏览器和窗口尺寸。

每条反馈拥有编号和独立沟通历史。状态为待处理、待补充、已采纳、处理中、已完成、已关闭。处理人更新状态时必须填写说明；已完成应对应用户环境中已上线或已确认的结果。用户补充待补充项后回到待处理；已完成或已关闭的反馈可以说明原因重新打开。撤回采用关闭方式保留历史。

回复和状态变化带版本检查；其他人已更新时会提示冲突，保留本次输入并刷新详情。详情支持加载更早记录，不截断长历史。关闭未发送内容会要求确认。

## 通知

新反馈与用户补充通知反馈处理人；处理人的回复和状态变化通知提交者。操作人不会收到自己的通知。通知持久化，离线后登录仍可查看；小铃铛当前每 60 秒刷新一次未读数。点击反馈通知直接打开对应反馈。

通知失败不会回滚已经保存的反馈。服务端每分钟从待投递事件补发，事件与接收人组合通过唯一索引防止重复通知。反馈数据独立于讨论历史，不受聊天消息清理影响。本版提供站内通知，未接入站外邮件或手机推送。

## 文件位置与资源保护

图片根目录复用服务器 `UPLOAD_DIR`。生产环境已核实为 `/www/personal-blog/uploads`，反馈图片位于：

```text
/www/personal-blog/uploads/feedback/YYYY/MM/随机文件名.png
```

图片登记为 `Media`，分类「意见反馈」、访问范围 `private`，通过 `feedback` 字段关联反馈。前端通过 `/api/feedback/attachments/:id` 的认证请求读取 Blob，提交者或获授权处理人之外的账号无法读取；`/uploads/feedback` 静态访问返回 404。

媒体库识别反馈引用，不允许将图片当作未引用资产删除，也不允许迁移分类改变访问属性。未登记资源扫描保护 `feedback` 目录，不能补登记为公开文件或按测试文件清理。图片属于运行数据，发布包不包含或覆盖它们。

## 开发与数据库初始化

- 后端：`backend/src/modules/feedback`，包含反馈、事件、校验、附件和通知服务。
- 前端：`frontend/src/views/console/FeedbackPage`，复用列表、提交和详情组件，普通与管理入口共用清晰的服务端权限边界。
- 自动化验证：`backend/tests/feedback.test.js`、`frontend/src/services/feedback.test.js`。

生产环境禁止通过应用启动隐式建立新索引。本次提供定向脚本：

```bash
cd backend
node src/scripts/initializeFeedback.js
# 检查 dry-run 输出，确认已有 mongodump 备份后应用
node src/scripts/initializeFeedback.js --apply
node src/scripts/initializeFeedback.js --verify
```

脚本只新增两个反馈菜单、首次个人入口授权及反馈所需索引，不重置其他菜单和业务数据。之后重复执行不会覆盖人工撤回的反馈权限。新的完整环境也可通过原有 RBAC 初始化获得菜单。

完整发布使用：

```powershell
pwsh -File scripts/deploy-release.ps1 -Target full -RunFeedbackMigration
```

该选项在发布流程已完成 MongoDB 备份后执行反馈 dry-run、apply 和 verify；无需同时运行全部历史数据库任务。后续普通修复不涉及菜单与索引时使用对应的 backend/frontend/full 目标，不再重复传迁移开关。

项目台账文件仍通过后台导入，不通过这次数据库初始化脚本写入。
