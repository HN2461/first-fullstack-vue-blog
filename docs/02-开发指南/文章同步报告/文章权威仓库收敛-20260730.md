## 排序收敛

- 27 个明确章节系列按标题中的第一篇、第二篇或 `00`、`01`、`02` 升序固化。
- 学习总目录和导航文章位于章节系列之前。
- Vue2 等同一分类含多套重复章节号的旧资料不做猜测性交叉重排，保留旧顺序。
- 文章和同级分类的 `sortOrder` 均收敛为 `10、20、30...`，系统默认分类保留 `-9999`。
- 文件管理器名称排序不代表线上目录顺序；线上与数据库均以 `sortOrder` 为准。

## 同步能力

- Markdown Front Matter 保存真实 `status`、`categoryPath`、`tags`、`sortOrder`、`publishedAt` 和 `updatedAt`。
- `manifest.json` 升级为 formatVersion 3，增加 97 个分类的路径、状态和排序元数据。
- 同步默认 dry-run；本地与生产写入使用不同的显式目标参数。
- 生产覆盖必须额外传入 `--target=production --confirm-production-replace`。
- 同 slug 但历史 ObjectId 不同时，同步脚本会统一到权威快照 ID，并迁移评论、互动和媒体关联。
- 阅读量、推荐状态、附件、评论和互动默认保留；只有显式 `--clean-orphans` 才清理历史孤立关系。

## 日常命令

```powershell
cd backend
npm run article-snapshot:prepare -- --publish-all
npm run article-snapshot:prepare:apply -- --publish-all
npm run article-snapshot:dry-run -- --publish-all
npm run article-snapshot:apply -- --publish-all
npm run article-snapshot:dry-run -- --publish-all
```

生产同步前必须额外完成生产 dry-run、`mongodump` 整库备份、专项 EJSON 备份、写后幂等 dry-run 和内外网健康检查。
