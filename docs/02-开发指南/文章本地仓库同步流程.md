# 文章本地仓库同步流程

## 目录定位

`output` 是文章内容的本地权威仓库，文章正文不再长期散落在多个导出目录中。

```text
output/
├─ 线上文章/
│  ├─ manifest.json
│  ├─ README.md
│  └─ 按线上分类路径存放的文章
└─ 未导入线上/
   └─ 尚未同步数据库的本地草稿和专题
```

- `线上文章`：文章的本地唯一权威源，与本地、生产数据库中的全部未删除文章对应；目录层级必须与分类路径一致。
- `未导入线上`：只放尚未进入线上数据库的内容，可以继续在本地完善和调整分类。
- 文章是否上线以数据库和 `manifest.json` 中的 `originalId`、`originalSlug` 为准，不能仅凭文件夹名称或标题判断。
- 对线上文章进行 AI 修改时，直接编辑 `线上文章` 中的对应文件，不再额外复制一份“修改版”。
- 差异分析报告统一写入 `docs/02-开发指南/文章同步报告`，不放在 `output` 内容目录中。
- 当前基线的文章全部为 `published`；未写完的新文只放在 `未导入线上`，不以草稿状态混入权威快照。

## 本地内容优先原则

- 历史本地文件可能比线上版本更新，必须比较正文、标题、摘要、标签、封面和分类后再选择保留版本。
- `originalId`、`originalSlug` 和线上导出时间只用于确认文章身份，不能用于判断哪份正文更新。
- 本地与线上正文有差异时，默认保留本地版本并进入待同步清单；不能使用线上快照直接覆盖。
- 线上不存在但本地存在的文章默认移入 `未导入线上`。只有明确确认永久废弃后才清理，并且清理前必须保留可恢复备份。
- 旧导出文件缺少的新字段，例如 `sortOrder`，可以从当前数据库补齐；字段缺失不代表本地正文是旧版本。

## 生成权威快照

在确认本地数据库已经与线上同步后执行：

```powershell
cd backend
npm run article-repository:export -- --output=../output/article-repository-latest.zip
```

导出命令使用原 slug，不追加 `revision-日期`。目标文件已存在时默认拒绝覆盖；确需覆盖时显式增加 `--force`。

ZIP 解压并通过 `manifest.json` 完整性校验后，才可以替换 `output/线上文章`。替换前必须备份旧目录，不能直接覆盖一份尚未验证的权威快照。

## 日常维护顺序

1. 从 `线上文章` 中找到原文章并直接修改；`originalId` 和 `originalSlug` 是稳定身份，标题、摘要、`categoryPath`、`tags`、`status`、`sortOrder` 和正文由 Front Matter 及 Markdown 维护。
2. 运行 `npm run article-snapshot:prepare -- --publish-all` 检查发布状态、重复排序和章节顺序；只在报告确认后运行 `npm run article-snapshot:prepare:apply -- --publish-all`。
3. 运行 `npm run article-snapshot:dry-run -- --publish-all`，检查更新、新增、删除和分类变化数量。
4. 运行 `npm run article-snapshot:apply -- --publish-all`；脚本会先生成 EJSON 备份，再重建本地文章、分类和标签。
5. 再次运行 dry-run，必须得到新增、更新、移除均为 0，且 513 篇当前基线全部已发布。
6. 生产同步前依次执行生产 dry-run、`mongodump` 整库备份和脚本 EJSON 专项备份；生产写入必须显式传入 `--target=production --confirm-production-replace`。
7. 同步保留同 ID 或同 slug 文章的阅读量、推荐状态、附件、评论和互动；历史孤立评论和互动默认也保留，只有专项审计后显式传入 `--clean-orphans` 才允许清理。
8. 新文章写完前放在 `未导入线上`；确认发布后再移入 `线上文章` 的真实分类路径并进入上述流程。

## 目录排序规则

- 数据库和线上目录以 `sortOrder` 升序为唯一排序权威，文件管理器的名称排序不代表线上顺序。
- 每个分类内的排序值规范为 `10、20、30...`，避免 `0` 和重复值导致时间字段参与排序。
- 同一分类有两篇以上明确标注“第 N 篇 / 章 / 节”或 `01-`、`02：` 时，按章节号升序；总目录和学习导航优先。
- 无章节号的分类保留当前线上顺序；如果同一分类出现多组重复章节号，视为多套教程混放，不自动交叉重排。

## 删除规则

- `线上文章` 中删除文件不等于自动删除数据库文章；删除线上文章必须使用支持删除预览的同步脚本，并显式确认影响范围。
- 当前导入页面只会创建新草稿或跳过重复文章，不能用于覆盖更新。
- 历史导出副本、重复目录和已经从线上删除的旧文章，在确认权威快照完整并完成备份后清理。
