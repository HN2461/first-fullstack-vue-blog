# 工具箱全量质量验收

日期：2026-11-21。范围：工具箱全部 29 项工具、公共文本工作区、JSON/Base64 专用编辑器，以及专注模式浮层。

## 验收原则

本轮使用正常向量、错误输入、数值/编码边界、实际组件挂载和异步状态回归检查功能。所有工具逐项核对实际入口与新逻辑的连接，避免只验证函数而页面仍保留旧算法。

用户确认的布局为：当前工具占完整宽度，功能操作集中在顶部，输入/结果尽量使用剩余空间，不再为两侧标签单独占行。查找和工具切换按需打开。业务弹窗复用全局偏上定位变量，不覆盖顶部间距。

本轮没有启动真实浏览器。CodeMirror 与 Ant Design Vue 的组件回归在 jsdom 中真实挂载，补充几何接口不代表真实像素排版或浏览器权限验收。Clipboard、文件选择与下载仍需要用户环境最终验收。

## JSON

- 格式化、压缩和校验使用语法树与原始 token，保留长整数、高精度小数、尾零、指数和负零，不经 JavaScript Number 重写数值。
- 支持 2 空格、4 空格、Tab 缩进；按键名排序支持只排序根对象或递归排序。
- 支持字符串转义/去转义、Unicode 转义/还原，以及 RFC 6901 JSON Pointer 节点提取。
- 支持对象、数组和基本值。严格拒绝注释、尾逗号和无效数字；错误提供行列及输入定位。
- 重复键保留并警告，不静默覆盖；Pointer 遇到重复键歧义时拒绝。
- 编辑器具备行号、语法高亮、查找替换、撤销重做、折叠展开、自动换行、同步滚动和仅看结果。
- 支持 UTF-8 本地文件导入、复制、结果下载和结果继续处理。文件头 BOM 在导入时去除，非法 UTF-8 明确拒绝。
- Worker 可取消、超过 8 秒停止。输入最多 2 Mi 字符，文件最多 2 MiB，嵌套最多 256 层，语法标记最多 50 万个，输出最多 8 Mi 字符。
- JSON 转义形式中的孤立代理项可原样保留；还原为无法无损 UTF-8 编码的纯文本时明确拒绝。

## Base64

- 使用 RFC 4648 标准与 URL-safe 字母表，支持有/无末尾填充，解码可自动识别字母表。
- 严格检查非法字符、混合字母表、填充位置/数量和非零尾部位；可明确选择是否忽略 ASCII 空白。
- UTF-8 文本可逆，保留中文、emoji、组合字符、NUL 和实际 BOM 字符。无效 UTF-8 不使用替换字符伪装成功。
- 支持任意本地文件编码和 Base64 文本文件导入。编码文件时左侧显示文件摘要，防止编辑中的文本被隐藏的文件字节忽略。
- 支持 base64 Data URL；标志必须位于元数据末尾，使用标准字母表，不渲染或执行解码内容。
- 解码可自动选择 UTF-8 或十六进制，也可明确指定展示方式。十六进制预览最多 64 KiB，完整原始字节仍可下载或继续编码。
- 支持设置、查找、撤销重做、换行、同步滚动、仅看结果、取消、复制及完整下载。输入或处理参数改变后，旧结果禁用复制、下载与继续处理。
- 单次原始/解码数据最多 2 MiB；Base64 原文接收最多 4 Mi 字符，以容纳 MIME 换行；编码文件最多 2 MiB，解码文件最多 3 MiB。Worker 超过 8 秒停止。

## 组件与运行边界

- 公共文本转换区对超限输入明确拒绝，保留原输入，不使用 maxlength 静默截断。
- CSV/Markdown 处理上限为 1 Mi 字符、10000 条数据记录加表头、1000 列；Query 最多 10000 个参数。文本统计最多 100000 字符，停止输入 150 毫秒后统计，等待期间不显示或复制旧结果。
- JSON/Base64 和 Regex 使用独立线程；普通文本处理有明确容量限制，不承诺无限大文件。
- 真实编辑器组件测试覆盖挂载、模型替换、撤销重做、只读、诊断定位、查找浮层、折叠、主题与销毁。
- 浮层组件测试覆盖最大化工作区之上的 Modal、Select 与 Popover，以及选择后实际筛选行为。
- 异步任务测试覆盖后发取消、超时、旧消息隔离、错误位置与缓存停用时释放线程。
- 输入、输出和文件仅保存在当前内存；不新增后端上传或持久化接口。长期上传资源规则不适用于这些有界、及时释放的转换输入。
- JWT 工具只解码，不验证签名或可信性。BMI 为成人参考指标，不作为诊断结论。颜色工具覆盖 HEX/RGB/HSL，未宣称完整 CSS 命名色或所有色彩空间。

## 官方依据

1. [RFC 8259](https://www.rfc-editor.org/rfc/rfc8259.txt)：JSON 语法、重复键与数值互操作边界。
2. [RFC 4648](https://www.rfc-editor.org/rfc/rfc4648.txt)：Base64 字母表、填充、尾部位与标准向量。
3. [Microsoft jsonc-parser](https://github.com/microsoft/node-jsonc-parser)：带 offset 的语法树、严格配置及文本格式编辑；本项目明确关闭注释和尾逗号。
4. [CodeMirror 基础配置](https://codemirror.net/examples/basic/) 与 [动态配置](https://codemirror.net/examples/config/)：真实编辑器、语言支持、Compartment 配置。文档服务无法连接时，API 同时核对当前安装包声明和实现。
5. [RFC 4180](https://www.rfc-editor.org/rfc/rfc4180.txt) 与 [Papa Parse 文档](https://www.papaparse.com/docs)：CSV 引号、字段换行与解析错误。
6. [CSS Color 4](https://www.w3.org/TR/css-color-4/)：HEX、RGB、HSL 与透明度。
7. [MDN URLSearchParams](https://developer.mozilla.org/en-US/docs/Web/API/URLSearchParams) 与 [entities](https://github.com/fb55/entities)：重复参数与纯文本实体处理。

参考资料用于确定规范与实现边界，不能代替本项目回归。验收结论以实际测试输出、构建和用户环境反馈为准。
